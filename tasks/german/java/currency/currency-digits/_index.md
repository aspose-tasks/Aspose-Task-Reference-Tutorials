# Wie man die MS Project-Währung mit Aspose.Tasks abruft

## Einführung
Wenn Sie sich fragen, **wie man ms project currency** Informationen aus einer Microsoft Project‑Datei erhält, sind Sie hier genau richtig. In diesem umfassenden Tutorial erfahren Sie, **wie man mit ms project currency** Werten mithilfe der Aspose.Tasks‑Bibliothek für Java arbeitet. Egal, ob Sie ein Reporting‑Tool, ein Migrations‑Utility entwickeln oder einfach die Währungseinstellungen aus einer **java project file** lesen müssen, führt Sie dieser Leitfaden durch jeden Schritt – vom Laden einer *.mpp*‑Datei bis zum Extrahieren der Währungsziffern. Am Ende können Sie ms project currency‑Daten in Ihren eigenen Anwendungen problemlos handhaben.

## Schnelle Antworten
- **Welche Bibliothek liest MS Project‑Dateien?** Aspose.Tasks for Java.  
- **Wie viele Code‑Zeilen werden benötigt, um die Währungsziffern zu erhalten?** Nur drei prägnante Zeilen, nachdem das Projekt geladen wurde.  
- **Benötige ich eine Lizenz für die Entwicklung?** Eine kostenlose Testversion reicht für Tests; für die Produktion ist eine kommerzielle Lizenz erforderlich.  
- **Welche Java‑Version wird unterstützt?** Java 8 oder höher (jedes JDK, das Aspose.Tasks ausführt).  
- **Kann ich andere Projekteigenschaften abrufen?** Ja – Aspose.Tasks stellt ein vollständiges Set an Projektfeldern bereit (z. B. Startdatum, Kostensätze usw.).

## Was ist ms project currency?
Die `ms project currency`‑Eigenschaft definiert die Anzahl der Dezimalstellen, die Microsoft Project bei der Anzeige von Geldbeträgen verwendet. Sie wird in der Projektdatei im Feld **CURRENCY_DIGITS** gespeichert und bestimmt, ob Beträge als ganze Zahlen, ein‑dezimal, zwei‑dezimal usw. angezeigt werden. Diese Einstellung beeinflusst direkt Budgetberichte, Kosten‑Roll‑Ups und jede Benutzeroberfläche, die Finanzzahlen anzeigt, und ist somit für einen genauen Datenaustausch unerlässlich.

## Warum Aspose.Tasks für die Handhabung von ms project currency verwenden?
Aspose.Tasks ermöglicht das Extrahieren der Währungsziffern, ohne Microsoft Project zu installieren, und das mit Unternehmens‑Performance. Die Bibliothek unterstützt **über 30 Jahre an Project‑Dateiversionen** – von Project 2000 bis Project 2024 – und deckt mehr als **150 verschiedene Dateischemata** ab. Das Laden eines 500‑Seiten‑Projekts dauert in der Regel weniger als **2 Sekunden** auf einem Standard‑Server, und Sie können nur die Felder abfragen, die Sie benötigen, wodurch der Speicherverbrauch selbst bei den größten Zeitplänen unter **50 MB** bleibt.

## Voraussetzungen
1. **Java Development Environment** – JDK 8 oder neuer, installiert und konfiguriert.  
2. **Aspose.Tasks for Java** – Laden Sie das neueste JAR von der offiziellen Seite herunter: [Aspose.Tasks for Java](https://releases.aspose.com/tasks/java/).  
3. **Basic Java knowledge** – Sie sollten in der Lage sein, ein Java‑Projekt zu erstellen, externe Bibliotheken hinzuzufügen und eine `main`‑Methode auszuführen.  

## Pakete importieren
Zuerst importieren wir die benötigten Klassen.  
Importieren Sie die `Project`‑Klasse und zugehörige Hilfsmittel aus der Aspose.Tasks‑Bibliothek.  
```java
import java.io.IOException;
import com.aspose.tasks.Prj;
import com.aspose.tasks.Project;
import com.aspose.tasks.SaveFileFormat;
```

## Schritt 1: Datenverzeichnis festlegen
Geben Sie den Ordner an, der Ihre **java project file** (`*.mpp`) enthält.  
```java
String dataDir = "Your Data Directory";
```
Ersetzen Sie `"Your Data Directory"` durch den absoluten oder relativen Pfad, in dem sich `project.mpp` befindet.

## Schritt 2: mpp‑Datei laden
Jetzt sehen wir, **wie man mpp**‑Dateien mit Aspose.Tasks lädt.  
Die `Project`‑Klasse repräsentiert eine Microsoft Project‑Datei und bietet Zugriff auf deren Eigenschaften.  
```java
Project project = new Project(dataDir + "project.mpp");
```
Stellen Sie sicher, dass der Dateiname exakt übereinstimmt; andernfalls wird eine `IOException` ausgelöst.

## Schritt 3: Währungsziffern abrufen
Mit dem geladenen Projekt lässt sich die **ms project currency**‑Ziffern mit einer einzigen Zeile extrahieren:  
Die Methode `getCurrencyDigits()` gibt die Anzahl der Dezimalstellen zurück, die für Geldbeträge definiert sind.  
```java
System.out.println(project.get(Prj.CURRENCY_DIGITS));
```
Der Aufruf liefert ein `Integer`, das die Anzahl der Dezimalstellen darstellt (z. B. `2` für Cent). Der Wert wird in der Konsole ausgegeben, kann aber auch in einer Variablen für weitere Verarbeitung gespeichert werden.

## Häufige Probleme & Tipps
- **Datei nicht gefunden** – überprüfen Sie den `dataDir`‑Pfad und stellen Sie sicher, dass der Dateiname korrekt ist, einschließlich der `.mpp`‑Erweiterung.  
- **Nicht unterstützte Dateiversion** – Aspose.Tasks unterstützt Project‑2000‑2024‑Formate; ältere oder beschädigte Dateien benötigen möglicherweise eine Konvertierung.  
- **Lizenz nicht gesetzt** – während der Entwicklung funktioniert eine Testversion, aber für die Produktion müssen Sie eine gültige Lizenz anwenden, um Evaluations‑Wasserzeichen zu vermeiden.
