# Как получить валюту проекта MS с помощью Aspose.Tasks

## Введение
Если вы задаётесь вопросом, **как получить информацию о валюте проекта MS** из файла Microsoft Project, вы попали в нужное место. В этом полном руководстве вы узнаете, **как работать со значениями валюты проекта MS** с помощью библиотеки Aspose.Tasks для Java. Независимо от того, создаёте ли вы инструмент отчётности, утилиту миграции или просто нужно прочитать настройки валюты из **файла проекта Java**, это руководство проведёт вас через каждый шаг — от загрузки файла *.mpp* до извлечения цифр валюты. К концу вы будете уверенно обрабатывать данные о валюте проекта MS в своих приложениях.

## Быстрые ответы
- **Какая библиотека читает файлы MS Project?** Aspose.Tasks for Java.  
- **Сколько строк кода требуется для получения цифр валюты?** Всего три короткие строки после загрузки проекта.  
- **Нужна ли лицензия для разработки?** Бесплатная пробная версия подходит для тестирования; для продакшна требуется коммерческая лицензия.  
- **Какая версия Java поддерживается?** Java 8 или выше (любой JDK, который запускает Aspose.Tasks).  
- **Могу ли я получить другие свойства проекта?** Да — Aspose.Tasks предоставляет полный набор полей проекта (например, дату начала, ставки затрат и т.д.).

## Что такое валюта проекта MS?
Свойство `ms project currency` определяет количество десятичных знаков, которое Microsoft Project использует при отображении денежных значений. Оно хранится в файле проекта в поле **CURRENCY_DIGITS** и определяет, будут ли суммы отображаться как целые числа, с одним, двумя и т.д. десятичными знаками. Эта настройка напрямую влияет на отчёты по бюджету, суммирование затрат и любой пользовательский интерфейс, показывающий финансовые цифры, делая её важной для точного обмена данными.

## Зачем использовать Aspose.Tasks для работы с валютой проекта MS?
Aspose.Tasks позволяет извлекать цифры валюты без установки Microsoft Project и делает это с производительностью уровня корпоративных решений. Библиотека поддерживает **более 30 лет версий файлов Project** — от Project 2000 до Project 2024 — охватывая более **150 различных схем файлов**. Загрузка проекта в 500 страниц обычно занимает менее **2 секунд** на стандартном сервере, и вы можете запрашивать только необходимые поля, удерживая использование памяти ниже **50 МБ**, даже для самых больших расписаний.

## Требования
1. **Среда разработки Java** — установленный и настроенный JDK 8 или новее.  
2. **Aspose.Tasks for Java** — скачайте последнюю JAR‑файл с официального сайта: [Aspose.Tasks for Java](https://releases.aspose.com/tasks/java/).  
3. **Базовые знания Java** — вы должны уметь создавать Java‑проект, добавлять внешние библиотеки и запускать метод `main`.  

## Импорт пакетов
Сначала импортируйте необходимые классы.  
Импортируйте класс `Project` и связанные утилиты из библиотеки Aspose.Tasks.  
```java
import java.io.IOException;
import com.aspose.tasks.Prj;
import com.aspose.tasks.Project;
import com.aspose.tasks.SaveFileFormat;
```

## Шаг 1: определить каталог данных
Укажите папку, содержащую ваш **файл проекта Java** (`*.mpp`).  
```java
String dataDir = "Your Data Directory";
```
Замените `"Your Data Directory"` на абсолютный или относительный путь, где находится `project.mpp`.

## Шаг 2: загрузить файл mpp
Теперь мы посмотрим, **как загружать файлы mpp** с помощью Aspose.Tasks.  
Класс `Project` представляет файл Microsoft Project и предоставляет доступ к его свойствам.  
```java
Project project = new Project(dataDir + "project.mpp");
```
Убедитесь, что имя файла точно совпадает; в противном случае будет выброшено `IOException`.

## Шаг 3: получить цифры валюты
После загрузки проекта извлечение цифр **ms project currency** — это однострочник:  
Метод `getCurrencyDigits()` возвращает количество десятичных знаков, определённых для денежных значений.  
```java
System.out.println(project.get(Prj.CURRENCY_DIGITS));
```
Вызов возвращает `Integer`, представляющий количество десятичных знаков (например, `2` для центов). Значение выводится в консоль, но вы также можете сохранить его в переменной для дальнейшей обработки.

## Распространённые проблемы и советы
- **Файл не найден** — дважды проверьте путь `dataDir` и убедитесь, что имя файла правильное, включая расширение `.mpp`.  
- **Неподдерживаемая версия файла** — Aspose.Tasks поддерживает форматы Project 2000‑2024; более старые или повреждённые файлы могут потребовать конвертации.  
- **Лицензия не установлена** — во время разработки работает пробная версия, но для продакшна необходимо применить действующую лицензию, чтобы избежать водяных знаков оценки.
