# Как отслеживать сверхурочную работу и затраты труда с помощью Aspose.Tasks

В этом руководстве вы узнаете **как отслеживать сверхурочную работу** и затраты труда, используя Aspose.Tasks для Java. Мы пройдем процесс загрузки файла MPP, перебора назначений ресурсов и извлечения данных о сверхурочной работе, оставшейся работе и затратах, чтобы вы могли держать проекты в графике и в рамках бюджета.

## Быстрые ответы
- **Что я могу отслеживать?** Стоимость сверхурочной работы, сверхурочная работа, оставшиеся затраты, оставшийся объём работы и оставшиеся затраты на сверхурочную работу.  
- **Какая библиотека требуется?** Aspose.Tasks for Java.  
- **Нужна ли лицензия для разработки?** Бесплатная пробная версия подходит для тестирования; лицензия требуется для продакшн.  
- **Можно ли загрузить существующие файлы .mpp?** Да, просто укажите путь к файлу.  
- **Достаточно ли Java 6?** API поддерживает Java SE 6 и более новые версии.

## Как отслеживать сверхурочную работу и затраты труда?

Загрузите проект, пройдите по каждому `ResourceAssignment` и прочитайте свойства, связанные со сверхурочной работой — весь процесс можно выполнить менее чем в десяти строках кода Java. API возвращает значения в валютных единицах проекта, и вы можете комбинировать их с другими метриками для создания полной панели мониторинга затрат.

## Что такое мониторинг затрат проекта?

Мониторинг затрат проекта — это непрерывный процесс отслеживания запланированных, фактических и прогнозируемых расходов по всем ресурсам проекта. Он предоставляет информацию в реальном времени о том, куда идут деньги, помогает раннее выявлять перерасходы из‑за сверхурочной работы и обеспечивает точное прогнозирование оставшейся работы.

## Почему важно отслеживать сверхурочную работу и оставшийся объём работы?

Сверхурочная работа является основной причиной неожиданных перерасходов бюджета, составляя до **35 %** отклонения стоимости во многих крупномасштабных проектах. Измеряя сверхурочную работу и оставшийся объём работы, вы можете:
- **Контроль бюджета:** Обнаруживать резкие скачки стоимости до того, как они станут критическими.  
- **Улучшение прогнозирования:** Корректировать графики на основе оценок оставшейся работы, сокращая отклонения расписания до **20 %**.  
- **Повышение прозрачности:** Предоставлять заинтересованным сторонам конкретные цифры вместо расплывчатых оценок.

## Импорт пакетов

Следующие импорты дают доступ к основным классам управления проектами, которые вам понадобятся. Asn — вспомогательный класс для работы с данными, специфичными для назначений.

```java
import com.aspose.tasks.Asn;
import com.aspose.tasks.Project;
import com.aspose.tasks.ResourceAssignment;
```

## Шаг 1: Настройка каталога данных

Определите папку, содержащую ваш файл MPP. Использование абсолютного или относительного пути работает одинаково.

```java
String dataDir = "Your Data Directory";
```  
Замените `"Your Data Directory"` на путь к вашему файлу проекта.

## Шаг 2: Загрузка проекта

`Project` — это объект верхнего уровня Aspose.Tasks, представляющий полностью загруженный в память файл Microsoft Project. Его создание загружает файл и подготавливает все внутренние коллекции к использованию.

```java
Project project = new Project(dataDir + "ResourceAssignmentOvertimes.mpp");
```  
Замените `"ResourceAssignmentOvertimes.mpp"` на имя вашего файла MPP. Этот шаг демонстрирует использование **load mpp file**.

## Шаг 3: Итерация по назначенным ресурсам

`ResourceAssignment` — это связь между ресурсом и задачей, раскрывающая детали стоимости, работы и сверхурочной работы. Перебор коллекции позволяет исследовать каждое назначение отдельно.

```java
for (ResourceAssignment ra : project.getResourceAssignments()) {
```

## Шаг 4: Вывод затрат на сверхурочную работу и объёма работы

Получите метрики, связанные со сверхурочной работой, напрямую из каждого `ResourceAssignment`. Эти значения выражены в валютных и временных единицах проекта.

```java
    System.out.println(ra.get(Asn.OVERTIME_COST));
    System.out.println(ra.get(Asn.OVERTIME_WORK).toString());
```

## Шаг 5: Вывод оставшихся затрат и объёма работы

API предоставляет свойства `RemainingCost` и `RemainingWork`, отражающие прогнозируемые усилия и расходы, необходимые для завершения каждого назначения.

```java
    System.out.println(ra.get(Asn.REMAINING_COST));
    System.out.println(ra.get(Asn.REMAINING_WORK).toString());
```

## Шаг 6: Вывод оставшихся затрат и объёма сверхурочной работы

`RemainingOvertimeCost` и `RemainingOvertimeWork` дают чёткую картину дополнительного бюджета и усилий, ожидаемых из‑за сверхурочной работы.

```java
    System.out.println(ra.get(Asn.REMAINING_OVERTIME_COST));
    System.out.println(ra.get(Asn.REMAINING_OVERTIME_WORK).toString());
}
```

## Распространённые проблемы и решения
- **Файл не найден:** Проверьте путь `dataDir` и убедитесь, что имя файла MPP указано правильно.  
- **Null‑значения:** В некоторых назначениях может отсутствовать информация о сверхурочной работе; проверяйте `null` при выводе.  
- **Несоответствие версий:** Используйте версию библиотеки, соответствующую формату файла MPP (например, более новые версии MS Project).
