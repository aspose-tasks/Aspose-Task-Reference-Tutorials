## Saving options: save project as PDF, convert, and manage with ease
Explore step‑by‑step tutorials on saving options in Aspose.Tasks for .NET. Learn how to efficiently save, convert, and manage MS Project files in various formats such as HTML, images, PDFs, Primavera, templates, and more. Elevate your file management game and streamline your project workflows.

```csharp
using Aspose.Tasks;
using System;

class SaveAsPdfExample
{
    static void Main()
    {
        // Load an existing project
        Project project = new Project("MyProject.mpp");

        // Save the project as PDF
        project.Save("MyProject.pdf", SaveFileFormat.Pdf);

        Console.WriteLine("Project saved as PDF successfully.");
    }
}
```
