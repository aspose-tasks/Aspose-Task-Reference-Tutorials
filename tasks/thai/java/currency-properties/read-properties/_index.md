# วิธีการรับสัญลักษณ์สกุลเงินใน Java ด้วย Aspose.Tasks

## บทนำ
ในบทแนะนำนี้คุณจะ **get currency symbol java** และ **extract currency code java** จากไฟล์ Microsoft Project (*.mpp*) โดยใช้ Aspose.Tasks for Java API Aspose.Tasks ทำงานบนแพลตฟอร์มใด ๆ ที่รองรับ Java ดังนั้นคุณไม่จำเป็นต้องติดตั้ง Microsoft Project บนเครื่องของคุณเอง เมื่อจบคู่มือคุณจะสามารถอ่านรหัสสกุลเงิน ISO, สัญลักษณ์ที่แสดง, จำนวนตำแหน่งทศนิยม, และตำแหน่งของสัญลักษณ์โดยตรงจากไฟล์โครงการ ซึ่งช่วยให้คุณสามารถใส่เมตาดาต้าเงินที่แม่นยำลงในรายงาน, ระบบ ERP หรือแดชบอร์ดที่กำหนดเองได้

## คำตอบอย่างรวดเร็ว
- **What does “get currency symbol java” mean?** หมายถึงการดึงข้อมูลเมตาดาต้าเกี่ยวกับสกุลเงิน (รหัส, สัญลักษณ์, จำนวนตำแหน่งทศนิยม, ตำแหน่ง) จากไฟล์ MS Project ผ่านโค้ด Java  
- **Do I need a license to try this?** มีการทดลองใช้งานฟรีของ Aspose.Tasks; จำเป็นต้องมีไลเซนส์เชิงพาณิชย์สำหรับการใช้งานในสภาพแวดล้อมการผลิต  
- **Which JDK version is required?** Java 8 หรือสูงกว่า  
- **Can I modify the currency settings after reading them?** ได้, Aspose.Tasks ให้คุณอ่านและเขียนคุณสมบัติสกุลเงินได้ทั้งสองอย่าง  
- **Is this compatible with all .mpp versions?** API รองรับไฟล์ที่สร้างด้วย Microsoft Project 2003‑2021

## อะไรคือ get currency symbol java?
การโหลดโครงการด้วย Aspose.Tasks และเรียกคีย์คุณสมบัติที่เหมาะสมจะคืนค่าสัญลักษณ์สกุลเงินที่ไฟล์ Project ดั้งเดิมใช้ การดำเนินการนี้ให้ตัวอักษรที่ตรงกัน (เช่น `$`, `€`, `¥`) ที่ปรากฏในรายงานที่สร้างโดย Microsoft Project วิธีนี้คืนอักขระที่ใช้สำหรับค่าการเงินอย่างแม่นยำ ทำให้รายงานที่สร้างขึ้นตรงกับการจัดรูปแบบและการตั้งค่าภูมิภาคของโครงการต้นฉบับ

## ทำไมต้องอ่านคุณสมบัติสกุลเงิน java ด้วย Aspose.Tasks?
คุณสามารถดึงการตั้งค่าสกุลเงินโดยไม่ต้องเปิด Microsoft Project ซึ่งช่วยประหยัดเวลาและทรัพยากรเซิร์ฟเวอร์ Aspose.Tasks ประมวลผลไฟล์ .mpp ขนาดประมาณ 200 หน้าในเวลาไม่ถึง 30 ms และสามารถจัดการไฟล์ขนาดถึง 500 MB โดยไม่ต้องโหลดเอกสารทั้งหมดเข้าสู่หน่วยความจำ — การอ้างอิงประสิทธิภาพเชิงปริมาณนี้ทำให้การประมวลผลเป็นกลุ่มเป็นไปได้

## ข้อกำหนดเบื้องต้น
1. **Java Development Kit (JDK)** – Java 8 หรือใหม่กว่า ติดตั้งและเพิ่มลงใน `PATH` ของคุณ  
2. **Aspose.Tasks for Java JAR** – ดาวน์โหลดไลบรารี Aspose.Tasks for Java ล่าสุดจาก [download the latest Aspose.Tasks for Java library](https://releases.aspose.com/tasks/java/) และเพิ่มลงใน classpath ของโครงการ  
3. (Optional) **License file** – ไฟล์ `.lic` ที่ถูกต้อง หากคุณวางแผนรันโค้ดในสภาพแวดล้อมการผลิต

## นำเข้าแพ็กเกจ
เริ่มต้นด้วยการนำเข้า namespace ของ Aspose.Tasks ที่จำเป็นสำหรับการจัดการโครงการ:

```java
import com.aspose.tasks.*;
```

## ขั้นตอนที่ 1: ตั้งค่าไดเรกทอรีโครงการของคุณ
กำหนดโฟลเดอร์ที่มีไฟล์ `.mpp` ที่คุณต้องการวิเคราะห์ การเก็บเส้นทางไว้ในตัวแปรทำให้โค้ดสามารถนำกลับมาใช้ใหม่และทดสอบได้ง่ายขึ้น:

```java
String dataDir = "Your Data Directory";
```

*Replace `"Your Data Directory"` with the absolute or relative path to the folder where `project.mpp` resides.*

## ขั้นตอนที่ 2: สร้างอินสแตนซ์ตัวอ่านโครงการ
คลาส `Project` เป็นอ็อบเจ็กต์หลักของ Aspose.Tasks ที่แทนไฟล์ Microsoft Project ในหน่วยความจำ การโหลดไฟล์จะให้คุณเข้าถึงคุณสมบัติระดับโครงการทั้งหมด รวมถึงการตั้งค่าสกุลเงิน:

```java
Project project = new Project(dataDir + "project.mpp");
```

## ขั้นตอนที่ 3: แสดงคุณสมบัติสกุลเงิน
enumeration `Prj` ให้คีย์สำหรับคุณสมบัติโครงการ เช่น การตั้งค่าสกุลเงิน คุณสามารถสอบถามแต่ละคีย์ด้วย `project.get(...)` และแปลงผลลัพธ์เป็นประเภทที่อ่านได้:

```java
System.out.println("Currency Code : " + project.get(Prj.CURRENCY_CODE).toString());
System.out.println("<br>Currency Digits : " + project.get(Prj.CURRENCY_DIGITS).toString());
System.out.println("<br>Currency Symbol : " + project.get(Prj.CURRENCY_SYMBOL).toString());
System.out.println("Currency Symbol Position : " + project.get(Prj.CURRENCY_SYMBOL_POSITION).toString());
```

**What you’ll see:**  
- **Currency Code** – รหัส ISO‑4217 เช่น `USD`, `EUR`, `JPY`  
- **Currency Digits** – ปกติคือ `2` สำหรับสกุลเงินส่วนใหญ่, `0` สำหรับเยนญี่ปุ่น  
- **Currency Symbol** – ตัวอักษรที่แสดงในรายงาน (`$`, `€`, `¥`)  
- **Currency Symbol Position** – `0` สำหรับ **before** จำนวน, `1` สำหรับ **after**

## วิธีการรับสัญลักษณ์สกุลเงิน java?
โหลดโครงการของคุณแล้วเรียก `project.get(Prj.CURRENCY_SYMBOL)`; เมธอดนี้จะคืนสตริงสัญลักษณ์ที่ไฟล์ใช้ บรรทัดเดียวนี้เพียงพอที่จะส่งสัญลักษณ์ไปยัง UI การเงินหรือเครื่องมือรายงานอื่น ๆ คุณสามารถเก็บสตริงนี้ในตัวแปร, บันทึกลงล็อก, หรือส่งต่อให้ส่วนประกอบอื่น ๆ ที่ต้องการสัญลักษณ์สกุลเงินสำหรับการแสดงผลหรือการคำนวณ

## ขั้นตอนที่ 4: การเสร็จสิ้นการประมวลผล
สัญญาณว่าการสกัดข้อมูลเสร็จสมบูรณ์อย่างประสบความสำเร็จ ข้อความง่าย ๆ นี้มีประโยชน์เมื่อโค้ดทำงานเป็นส่วนหนึ่งของงานแบตช์ขนาดใหญ่:

```java
System.out.println("Process completed Successfully");
```
