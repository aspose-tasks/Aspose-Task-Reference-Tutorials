# วิธีสร้างแอตทริบิวต์ขยายของงานด้วย Aspose.Tasks Java

## บทนำ
ในบทเรียนนี้คุณจะได้เรียนรู้วิธี **สร้างแอตทริบิวต์ขยายของงาน** ในไฟล์ Microsoft Project โดยใช้ Aspose.Tasks for Java การเพิ่มฟิลด์แบบกำหนดเองช่วยให้คุณบันทึกข้อมูลเฉพาะโครงการที่ไม่ได้ครอบคลุมโดยคอลัมน์ที่มีอยู่แล้ว ทำให้คุณควบคุมการรายงานและการวางแผนทรัพยากรได้ละเอียดขึ้น เมื่อจบคู่มือคุณจะสามารถเพิ่มแอตทริบิวต์แบบข้อความธรรมดา, แบบมีการค้นหา, และแบบระยะเวลาให้กับงานใด ๆ ได้

## คำตอบอย่างรวดเร็ว
- **อะไรคือ “extended attribute”**? เป็นฟิลด์แบบกำหนดเองที่คุณสร้างและแนบไปยังงาน, ทรัพยากร, หรือการมอบหมาย.  
- **ไลบรารีใดที่เพิ่มความสามารถนี้?** Aspose.Tasks for Java, ไลบรารีการจัดการโครงการสำหรับ Java.  
- **ฉันต้องมีลิขสิทธิ์เพื่อทดลองใช้งานหรือไม่?** ใช่ – มีการทดลองใช้งานฟรี 30 วันจากเว็บไซต์ของ Aspose.  
- **ฉันสามารถเพิ่มค่าการค้นหาได้หรือไม่?** แน่นอน; คุณสามารถจัดหารายการค่าที่อนุญาตสำหรับฟิลด์ข้อความหรือระยะเวลา.  
- **API รองรับ Java 8 และรุ่นต่อไปหรือไม่?** ใช่, รองรับ Java 8+ และทำงานบนระบบปฏิบัติการหลักทั้งหมด.  

## แอตทริบิวต์ขยายของงานคืออะไร?
แอตทริบิวต์ขยายของงานคือคอลัมน์ที่ผู้ใช้กำหนดซึ่งเก็บข้อมูลเพิ่มเติมสำหรับแต่ละงานในไฟล์ Project มันทำงานเหมือนฟิลด์ที่มีอยู่แล้วแต่สามารถเก็บประเภทข้อมูลใด ๆ ที่คุณต้องการ เช่น ข้อความ, ตัวเลข, วันที่, หรือระยะเวลา.

## ทำไมต้องใช้ Aspose.Tasks for Java?
Aspose.Tasks รองรับ **ไฟล์ฟอร์แมตกว่า 50** และสามารถประมวลผลโครงการที่มี **งานกว่า 10,000** ได้โดยไม่ต้องติดตั้ง Microsoft Project ไลบรารีทำงานแบบออฟไลน์ทั้งหมด รับประกันความเป็นส่วนตัวของข้อมูลและประสิทธิภาพที่คาดเดาได้สำหรับโซลูชันระดับองค์กร.

## ข้อกำหนดเบื้องต้น
- ความรู้พื้นฐานการเขียนโปรแกรม Java.  
- ไลบรารี Aspose.Tasks for Java ติดตั้งแล้ว คุณสามารถดาวน์โหลดได้จาก [website](https://releases.aspose.com/tasks/java/).  
- IDE สำหรับ Java (IntelliJ IDEA, Eclipse หรือ VS Code) ตั้งค่าไว้บนเครื่องของคุณ.

## นำเข้าแพ็กเกจ
คำสั่ง `import` ให้คุณเข้าถึงคลาสหลักที่จำเป็น เช่น `Project`, `ExtendedAttributeDefinition` และ `ExtendedAttribute`.  
`Project` แทนไฟล์ Microsoft Project และให้เมธอดสำหรับอ่าน, แก้ไข, และบันทึกไฟล์.  
`ExtendedAttributeDefinition` กำหนดฟิลด์แบบกำหนดเองที่สามารถแนบไปยังงาน, ทรัพยากร, หรือการมอบหมาย.  
`ExtendedAttribute` เป็นอินสแตนซ์ของการกำหนดที่เก็บค่าจริงสำหรับเอนทิตีเฉพาะ.

## วิธีเพิ่มแอตทริบิวต์ขยายแบบข้อความธรรมดาให้กับงาน?
เพื่อเพิ่มแอตทริบิวต์ขยายแบบข้อความธรรมดา คุณต้องโหลดโครงการก่อน, จากนั้นสร้างการกำหนดประเภท Text, เพิ่มลงในคอลเลกชันของโครงการ, สร้างงาน, สร้างอินสแตนซ์ของแอตทริบิวต์จากการกำหนด, ตั้งค่าข้อความ, แนบไปยังงาน, และสุดท้ายบันทึกโครงการ.

### 1. ตั้งค่าเส้นทางไดเรกทอรีเอกสาร
ระบุที่ตั้งของไฟล์ต้นฉบับและไฟล์ผลลัพธ์ของคุณ.

```java
import java.io.IOException;
import com.aspose.tasks.*;
```

### 2. สร้างโครงการใหม่
สร้างอ็อบเจ็กต์ `Project` ขึ้นมา, สามารถโหลดไฟล์ .mpp ที่มีอยู่แล้วได้ตามต้องการ.

```java
String dataDir = "Your Document Directory";
```

### 3. สร้างการกำหนดแอตทริบิวต์ขยายประเภท Text1
กำหนดฟิลด์แบบกำหนดเองเป็นคอลัมน์ข้อความธรรมดาชื่อ “Text1”.

```java
Project project = new Project(dataDir + "project.mpp");
```

### 4. เพิ่มการกำหนดลงในคอลเลกชันแอตทริบิวต์ขยายของโครงการ
ลงทะเบียนการกำหนดใหม่เพื่อให้โครงการรับรู้.

```java
ExtendedAttributeDefinition taskExtendedAttributeText1Definition = ExtendedAttributeDefinition.createTaskDefinition(CustomFieldType.Text, ExtendedAttributeTask.Text1, "Task City Name");
```

### 5. เพิ่มงานลงในโครงการ
สร้างงานที่จะรับฟิลด์แบบกำหนดเอง.

```java
project.getExtendedAttributes().add(taskExtendedAttributeText1Definition);
```

### 6. สร้างแอตทริบิวต์ขยายจากการกำหนดแอตทริบิวต์
สร้างอินสแตนซ์ที่คุณสามารถผูกกับงานเฉพาะได้.

```java
Task task = project.getRootTask().getChildren().add("Task 1");
```

### 7. กำหนดค่าต่าง ๆ ให้กับแอตทริบิวต์ขยายที่สร้างขึ้น
ตั้งค่าข้อความจริงที่คุณต้องการเก็บ, เช่น “Design Review”.

```java
ExtendedAttribute taskExtendedAttributeText1 = taskExtendedAttributeText1Definition.createExtendedAttribute();
```

### 8. เพิ่มแอตทริบิวต์ขยายลงในงาน
แนบอินสแตนซ์ของแอตทริบิวต์ไปยังคอลเลกชัน `ExtendedAttributes` ของงาน.

```java
taskExtendedAttributeText1.setTextValue("London");
```

### 9. บันทึกโครงการ
เขียนโครงการที่อัปเดตกลับไปยังดิสก์ในรูปแบบที่ต้องการ.

```java
task.getExtendedAttributes().add(taskExtendedAttributeText1);
```

## วิธีเพิ่มแอตทริบิวต์ข้อความพร้อมตัวเลือกการค้นหา?
เมื่อเพิ่มแอตทริบิวต์ข้อความพร้อมการค้นหา คุณทำตามขั้นตอนเดียวกับแอตทริบิวต์ข้อความธรรมดา แต่ก่อนเพิ่มการกำหนดคุณต้องเติมคอลเลกชัน `LookupValues` ด้วยสตริงที่อนุญาต ค่าต่าง ๆ นี้จะแสดงเป็นรายการดรอป‑ดาวน์ใน Microsoft Project เพื่อให้ข้อมูลสอดคล้องกัน.

## วิธีเพิ่มแอตทริบิวต์ระยะเวลาพร้อมตัวเลือกการค้นหา?
เพื่อเพิ่มแอตทริบิวต์ระยะเวลาพร้อมการค้นหา ให้เปลี่ยนประเภท `Text1` เป็น `Duration2` เมื่อสร้างการกำหนด แล้วเติมคอลเลกชัน `LookupValues` ด้วยสตริงระยะเวลา เช่น “1 day”, “2 days” เป็นต้น หลังจากเพิ่มการกำหนดลงในโครงการแล้ว สร้างอินสแตนซ์ของแอตทริบิวต์ ตั้งค่าระยะเวลา, แนบไปยังงาน, และบันทึกไฟล์.

## ปัญหาทั่วไปและการแก้ไขข้อผิดพลาด
- **ค่าการค้นหาไม่แสดง** – ตรวจสอบว่าคุณได้เพิ่มรายการค้นหาแต่ละรายการลงในคอลเลกชัน `LookupValues` *ก่อน* เรียก `project.getExtendedAttributes().add(definition)`.  
- **ค่าแอตทริบิวต์ไม่ถูกบันทึก** – ยืนยันว่าคุณได้เพิ่มอินสแตนซ์ `ExtendedAttribute` ไปยังงาน *หลัง* ตั้งค่าค่าแล้ว.  
- **ขนาดไฟล์เพิ่มโดยไม่คาดคิด** – เมื่อทำงานกับโครงการขนาดใหญ่มาก, พิจารณาเรียก `project.setSaveOptions(new ProjectSaveOptions())` เพื่อเปิดใช้งานการบันทึกแบบเพิ่มส่วน.
