# วิธีรับสกุลเงินของ ms project ด้วย Aspose.Tasks

## บทนำ
หากคุณกำลังสงสัย **วิธีรับข้อมูลสกุลเงินของ ms project** จากไฟล์ Microsoft Project คุณมาถูกที่แล้ว ในบทแนะนำที่ครอบคลุมนี้คุณจะได้เรียนรู้ **วิธีทำงานกับค่า ms project currency** ด้วยไลบรารี Aspose.Tasks สำหรับ Java ไม่ว่าคุณจะสร้างเครื่องมือรายงาน, ยูทิลิตี้การย้ายข้อมูล, หรือแค่ต้องการอ่านการตั้งค่าสกุลเงินจาก **ไฟล์ java project** คู่มือนี้จะพาคุณผ่านทุกขั้นตอน—from การโหลดไฟล์ *.mpp* ไปจนถึงการสกัดตัวเลขสกุลเงิน เมื่อเสร็จสิ้นคุณจะมั่นใจในการจัดการข้อมูลสกุลเงินของ ms project ในแอปพลิเคชันของคุณเอง

## คำตอบอย่างรวดเร็ว
- **ไลบรารีอะไรที่อ่านไฟล์ MS Project?** Aspose.Tasks for Java.  
- **ต้องใช้กี่บรรทัดโค้ดเพื่อรับตัวเลขสกุลเงิน?** เพียงสามบรรทัดสั้น ๆ หลังจากโหลดโปรเจกต์แล้ว.  
- **ต้องใช้ไลเซนส์สำหรับการพัฒนาหรือไม่?** เวอร์ชันทดลองฟรีใช้ได้สำหรับการทดสอบ; ต้องมีไลเซนส์เชิงพาณิชย์สำหรับการใช้งานจริง.  
- **เวอร์ชัน Java ที่รองรับคืออะไร?** Java 8 หรือสูงกว่า (JDK ใดก็ได้ที่รัน Aspose.Tasks).  
- **สามารถดึงคุณสมบัติอื่นของ Project ได้หรือไม่?** ใช่ – Aspose.Tasks เปิดเผยชุดเต็มของฟิลด์ Project (เช่น วันที่เริ่มต้น, อัตราค่าใช้จ่าย, เป็นต้น).

## ms project currency คืออะไร?
`ms project currency` เป็นคุณสมบัติที่กำหนดจำนวนตำแหน่งทศนิยมที่ Microsoft Project ใช้เมื่อแสดงค่าการเงิน มันถูกเก็บในไฟล์ Project เป็นฟิลด์ **CURRENCY_DIGITS** และกำหนดว่าจำนวนจะแสดงเป็นจำนวนเต็ม, หนึ่งตำแหน่งทศนิยม, สองตำแหน่งทศนิยม ฯลฯ การตั้งค่านี้มีผลโดยตรงต่อรายงานงบประมาณ, การสรุปค่าใช้จ่าย, และ UI ใด ๆ ที่แสดงตัวเลขทางการเงิน ทำให้เป็นสิ่งสำคัญสำหรับการแลกเปลี่ยนข้อมูลที่แม่นยำ.

## ทำไมต้องใช้ Aspose.Tasks สำหรับจัดการ ms project currency?
Aspose.Tasks ช่วยให้คุณสกัดตัวเลขสกุลเงินได้โดยไม่ต้องติดตั้ง Microsoft Project และทำได้ด้วยประสิทธิภาพระดับองค์กร ไลบรารีรองรับ **เวอร์ชันไฟล์ Project มากกว่า 30 ปี** — ตั้งแต่ Project 2000 ถึง Project 2024 — ครอบคลุม **สคีม่าไฟล์ที่แตกต่างกว่า 150** การโหลดโครงการขนาด 500 หน้าโดยทั่วไปใช้เวลาไม่เกิน **2 วินาที** บนเซิร์ฟเวอร์มาตรฐาน และคุณสามารถสอบถามเฉพาะฟิลด์ที่ต้องการได้ ทำให้การใช้หน่วยความจำอยู่ต่ำกว่า **50 MB** แม้กับตารางเวลาที่ใหญ่ที่สุด.

## ข้อกำหนดเบื้องต้น
ก่อนเริ่ม, โปรดตรวจสอบว่าคุณมีสิ่งต่อไปนี้:

1. **Java Development Environment** – JDK 8 หรือใหม่กว่า ที่ติดตั้งและกำหนดค่าแล้ว.  
2. **Aspose.Tasks for Java** – ดาวน์โหลด JAR ล่าสุดจากเว็บไซต์อย่างเป็นทางการ: [Aspose.Tasks for Java](https://releases.aspose.com/tasks/java/).  
3. **Basic Java knowledge** – คุณควรคุ้นเคยกับการสร้างโปรเจกต์ Java, การเพิ่มไลบรารีภายนอก, และการรันเมธอด `main`.  

## นำเข้าแพ็กเกจ
ก่อนอื่น, ให้ import คลาสที่เราต้องการ. Import คลาส `Project` และยูทิลิตี้ที่เกี่ยวข้องจากไลบรารี Aspose.Tasks.  
```java
import java.io.IOException;
import com.aspose.tasks.Prj;
import com.aspose.tasks.Project;
import com.aspose.tasks.SaveFileFormat;
```

## ขั้นตอนที่ 1: กำหนดไดเรกทอรีข้อมูล
ระบุโฟลเดอร์ที่บรรจุ **ไฟล์ java project** (`*.mpp`).  
```java
String dataDir = "Your Data Directory";
```
แทนที่ `"Your Data Directory"` ด้วยเส้นทางแบบ absolute หรือ relative ที่ไฟล์ `project.mpp` อยู่.

## ขั้นตอนที่ 2: โหลดไฟล์ mpp
ตอนนี้เราจะดู **วิธีโหลดไฟล์ mpp** ด้วย Aspose.Tasks. คลาส `Project` แสดงไฟล์ Microsoft Project และให้เข้าถึงคุณสมบัติต่าง ๆ ของมัน.  
```java
Project project = new Project(dataDir + "project.mpp");
```
ตรวจสอบให้แน่ใจว่าชื่อไฟล์ตรงกันอย่างสมบูรณ์; มิฉะนั้นจะเกิด `IOException`.

## ขั้นตอนที่ 3: ดึงตัวเลขสกุลเงิน
เมื่อโหลดโปรเจกต์แล้ว, การสกัดตัวเลข **ms project currency** ทำได้ในบรรทัดเดียว: เมธอด `getCurrencyDigits()` จะคืนค่าจำนวนตำแหน่งทศนิยมที่กำหนดสำหรับค่าการเงิน.  
```java
System.out.println(project.get(Prj.CURRENCY_DIGITS));
```
การเรียกคืนค่าเป็น `Integer` ที่แสดงจำนวนตำแหน่งทศนิยม (เช่น `2` สำหรับเซนต์). ค่าจะถูกพิมพ์ออกที่คอนโซล, แต่คุณก็สามารถเก็บไว้ในตัวแปรเพื่อการประมวลผลต่อไปได้.

## ปัญหาทั่วไป & เคล็ดลับ
- **ไฟล์ไม่พบ** – ตรวจสอบเส้นทาง `dataDir` อีกครั้งและให้แน่ใจว่าชื่อไฟล์ถูกต้องรวมถึงส่วนขยาย `.mpp`.  
- **เวอร์ชันไฟล์ที่ไม่รองรับ** – Aspose.Tasks รองรับฟอร์แมต Project 2000‑2024; ไฟล์ที่เก่ากว่าหรือเสียหายอาจต้องแปลง.  
- **ไม่ได้ตั้งค่าไลเซนส์** – ระหว่างการพัฒนาตัวทดลองทำงานได้, แต่สำหรับการผลิตต้องใช้ไลเซนส์ที่ถูกต้องเพื่อหลีกเลี่ยงลายน้ำการประเมินผล.
