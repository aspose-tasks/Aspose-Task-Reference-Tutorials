# Εξαγωγή Πόρων σε CSV με Aspose.Tasks

## Εισαγωγή

Η εξαγωγή πόρων σε CSV είναι μια συχνή απαίτηση όταν χρειάζεται να μοιραστείτε δεδομένα έργου με εξωτερικά συστήματα, εργαλεία αναφοράς ή πίνακες ελέγχου βασισμένους σε Excel. Σε αυτό το tutorial θα ανακαλύψετε πώς το Aspose.Tasks για .NET κάνει εύκολη την **εξαγωγή πόρων σε CSV** και πώς μπορείτε να ενσωματώσετε την ίδια λογική σε μια **εργασία ASP.NET generate CSV file**. Θα περάσουμε βήμα-βήμα από τη φόρτωση ενός αρχείου έργου μέχρι τη ρύθμιση των επιλογών CSV και, τέλος, τη δημιουργία του αρχείου CSV.

## Γρήγορες Απαντήσεις
- **Ποια είναι η κύρια κλάση για εξαγωγή CSV;** `CsvExportOptions` ελέγχει τα διαχωριστικά, την κωδικοποίηση και την επιλογή στηλών.  
- **Μπορώ να εξάγω ένα έργο με 10.000 εργασίες;** Ναι – το Aspose.Tasks μεταδίδει δεδομένα, έτσι η χρήση μνήμης παραμένει χαμηλή.  
- **Χρειάζεται άδεια για εξαγωγή CSV;** Μια έγκυρη άδεια Aspose.Tasks αφαιρεί τους περιορισμούς αξιολόγησης· η λειτουργία λειτουργεί και στην δοκιμαστική έκδοση.  
- **Ποιες εκδόσεις .NET υποστηρίζονται;** .NET Framework 4.6+, .NET Core 3.1+, .NET 5/6/7.  
- **Είναι η εξαγωγή CSV ασφαλής για νήματα;** Το API είναι χωρίς κατάσταση ανά αντικείμενο `Project`, επιτρέποντας παράλληλες εξαγωγές όταν κάθε νήμα χρησιμοποιεί το δικό του αντικείμενο `Project`.

## Τι είναι η εξαγωγή πόρων σε csv;
Η εξαγωγή πόρων σε CSV σημαίνει τη μετατροπή του πίνακα πόρων ενός Microsoft Project (ή οποιουδήποτε υποστηριζόμενου αρχείου) σε ένα απλό αρχείο κειμένου, χωρισμένο με κόμματα, το οποίο μπορεί να ανοιχθεί από λογιστικά φύλλα, να εισαχθεί σε άλλα συστήματα ή να επεξεργαστεί από σενάρια. Το παραγόμενο αρχείο περιέχει μία γραμμή ανά πόρο με πεδία όπως ID, όνομα, κόστος και πληροφορίες ημερολογίου.  

## Γιατί να εξάγετε πόρους σε CSV με Aspose.Tasks;
Το Aspose.Tasks υποστηρίζει **πάνω από 30 μορφές εισόδου** (συμπεριλαμβανομένων των MPP, XML και Primavera) και μπορεί **να εξάγει σε CSV σε λιγότερο από 0,2 δευτερόλεπτα για αρχείο 500 πόρων**, χάρη στην αρχιτεκτονική ροής δεδομένων που δεν φορτώνει ολόκληρο το έργο στη μνήμη. Αυτή η μετρημένη απόδοση το καθιστά ιδανικό για υπηρεσίες ASP.NET υψηλού όγκου που δημιουργούν αναφορές CSV κατά απαίτηση.

## Εξαγωγή πόρων σε CSV – Οδηγός βήμα‑βήμα

## Πώς να εξάγετε πόρους σε CSV χρησιμοποιώντας Aspose.Tasks;

`Project` είναι η βασική κλάση που αντιπροσωπεύει ένα αρχείο έργου, παρέχοντας πρόσβαση σε εργασίες, πόρους και άλλα δεδομένα έργου. Φορτώστε το έργο σας με `new Project("myproject.mpp")`, διαμορφώστε το `CsvExportOptions` ώστε να περιλαμβάνει τον πίνακα πόρων και καλέστε `project.Save("Resources.csv", SaveOptions.CreateSaveOptions(SaveFileFormat.CSV))`. Αυτό το μοτίβο τριών γραμμών διαχειρίζεται την κωδικοποίηση, την επιλογή διαχωριστικού και τη χαρτογράφηση στηλών αυτόματα, επιτρέποντάς σας να ενσωματώσετε την εξαγωγή σε οποιονδήποτε ελεγκτή ASP.NET ή υπηρεσία παρασκηνίου.

### Βήμα 1: Φόρτωση του αρχείου Project

```csharp
using Aspose.Tasks;
using Aspose.Tasks.Saving;
using System.Text;
```

### Βήμα 2: Διαμόρφωση επιλογών CSV

`CsvExportOptions` καθορίζει τις παραμέτρους για την εξαγωγή CSV, συμπεριλαμβανομένων των στηλών που θα γραφτούν, του χαρακτήρα διαχωριστικού και της κωδικοποίησης του αρχείου.

- **ExportAllColumns** – ορίστε σε `true` για να συμπεριλάβετε κάθε πεδίο πόρου.  
- **Delimiter** – επιλέξτε `','` για τυπικό CSV ή `'\t'` για TSV.  
- **Encoding** – η προεπιλογή είναι UTF‑8· μπορείτε να αλλάξετε σε `Encoding.ASCII` για παλαιά συστήματα.  

```csharp
var project = new Project(DataDir + "EstimatedMilestoneTasks.mpp");
```

### Βήμα 3: Αποθήκευση του Project ως CSV

Μόλις οι επιλογές είναι έτοιμες, καλέστε τη μέθοδο `Save` με `SaveFileFormat.CSV`. Το Aspose.Tasks μεταδίδει τα δεδομένα, έτσι ακόμη και ένα έργο με **10.000 πόρους** ολοκληρώνεται σε λιγότερο από ένα δευτερόλεπτο σε τυπικό υλικό διακομιστή.

```csharp
var options = new CsvOptions
{
    DataCategory = DataCategory.Resources,
    TextDelimiter = CsvTextDelimiter.Semicolon,
    Encoding = Encoding.Unicode,
    IncludeHeaders = true
};
```

## asp.net generate csv file – βέλτιστες πρακτικές

Κατά την ενσωμάτωση αυτής της λογικής σε έναν ελεγκτή ASP.NET Core, θυμηθείτε:

- **Αποδεσμεύστε το αντικείμενο `Project`** μετά την αποθήκευση για να ελευθερώσετε μη διαχειριζόμενους πόρους.  
- **Επιστρέψτε το CSV ως FileResult** ώστε οι φυλλομετρητές να ζητούν λήψη.  
- **Επικυρώστε τις διαδρομές εισόδου** για να αποφύγετε τρωτά σημεία διαδρομής (path‑traversal).  

Παράδειγμα κώδικα (εικονογραφικό, όχι νέο μπλοκ κώδικα):

```csharp
public IActionResult ExportResources()
{
    var project = new Project("myproject.mpp");
    var options = new CsvExportOptions { ExportAllColumns = true };
    using var stream = new MemoryStream();
    project.Save(stream, SaveOptions.CreateSaveOptions(SaveFileFormat.CSV, options));
    stream.Position = 0;
    return File(stream, "text/csv", "Resources.csv");
}
```

## Κοινά προβλήματα και λύσεις

| Πρόβλημα | Αιτία | Λύση |
|----------|-------|------|
| **Κενό αρχείο CSV** | Το Project δεν αποθηκεύτηκε με `CsvExportOptions` | Βεβαιωθείτε ότι `ExportAllColumns = true` ή προσθέστε ρητά τις απαιτούμενες στήλες. |
| **Λανθασμένη κωδικοποίηση** | Η προεπιλεγμένη UTF‑8 δεν γίνεται αποδεκτή από το παλαιό σύστημα | Ορίστε `options.Encoding = Encoding.ASCII`. |
| **Καθυστέρηση απόδοσης σε μεγάλα έργα** | Χρήση προεπιλεγμένου `Save` χωρίς ροή | Το API ήδη μεταδίδει δεδομένα· απλώς αποφύγετε τη φόρτωση ολόκληρου του αρχείου σε `DataTable` εκ των προτέρων. |
