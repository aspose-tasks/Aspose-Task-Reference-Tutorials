# Διαβάζοντας ιδιότητες νομίσματος Java με Aspose.Tasks

## Εισαγωγή
Σε αυτό το σεμινάριο θα μάθετε πώς να **αλλάζετε τη μορφή νομίσματος** και να διαβάζετε τις ιδιότητες νομίσματος σε έργα Java που χρησιμοποιούν το Aspose.Tasks. Τα ακριβή οικονομικά δεδομένα είναι απαραίτητα για πολυεθνικές ομάδες, και η εξοικείωση με αυτά τα API σας επιτρέπει να εξάγετε τον κωδικό ISO‑4217, να ανακτήσετε το σύμβολο του νομίσματος και να ενημερώσετε τις νομισματικές ρυθμίσεις του έργου χωρίς χειροκίνητες επεμβάσεις σε λογιστικά φύλλα.

## Γρήγορες απαντήσεις
- **Τι σημαίνει “read currency”;** Σημαίνει την εξαγωγή του κωδικού νομίσματος, του συμβόλου και των ρυθμίσεων μορφοποίησης αριθμών που αποθηκεύονται μέσα σε ένα αρχείο Project.  
- **Γιατί να προσαρμόσετε τις ρυθμίσεις νομίσματος;** Για να ευθυγραμμίσετε τις αναφορές κόστους με τις περιφερειακές συνήθειες και να αποφύγετε λάθη μετατροπής.  
- **Χρειάζομαι άδεια;** Ναι – απαιτείται έγκυρη άδεια Aspose.Tasks for Java για παραγωγική χρήση· μια δωρεάν δοκιμή λειτουργεί για αξιολόγηση.  
- **Ποιες εκδόσεις του Project υποστηρίζονται;** Τanto τα *.mpp* (Project 2007‑2024) όσο και τα *.xml* μορφές υποστηρίζονται πλήρως, καλύπτοντας πάνω από 20 χρόνια εκδόσεων αρχείων.  
- **Απαιτείται κάποια πρόσθετη ρύθμιση;** Απλώς προσθέστε το JAR του Aspose.Tasks for Java στο classpath σας και εισάγετε τις σχετικές κλάσεις.  

## Διαβάζοντας ιδιότητες νομίσματος Java σε έργα Aspose.Tasks
Στον δυναμικό χώρο της διαχείρισης έργων, η εξαγωγή λεπτομερειών νομίσματος είναι απαραίτητη για ακριβή ανάλυση κόστους. Ο αφιερωμένος οδηγός μας **[Reading Currency Properties in Aspose.Tasks Projects](./read-properties/)** σας καθοδηγεί βήμα προς βήμα—από το άνοιγμα ενός αρχείου έργου μέχρι την ανάκτηση του κωδικού νομίσματος, του συμβόλου και της μορφής. Ακολουθώντας το σεμινάριο θα μπορείτε να:
* Ανακτήσετε τον κωδικό νομίσματος (π.χ., USD, EUR) που χρησιμοποιείται σε όλο το έργο.  
* Πρόσβαση στο σύμβολο νομίσματος και στις ρυθμίσεις μορφοποίησης αριθμών.  
* Χρησιμοποιήσετε αυτές τις πληροφορίες για τη δημιουργία τοπικοποιημένων αναφορών κόστους ή για την τροφοδοσία οικονομικών ταμπλό.  

Η κατανόηση του τρόπου ανάγνωσης του νομίσματος εξασφαλίζει ότι μπορείτε να ελέγχετε τους προϋπολογισμούς των έργων, να συγκρίνετε τα κόστη μεταξύ περιοχών και να διατηρείτε τη συμμόρφωση με τα λογιστικά πρότυπα.

## Πώς να εξάγετε τον κωδικό νομίσματος java με Aspose.Tasks
Η μέθοδος `Project.getCurrencyCode()` επιστρέφει τον τριψήφιο αναγνωριστικό ISO‑4217 για τη νομισματική μονάδα του έργου.

**Άμεση απάντηση:** Καλέστε `project.getCurrencyCode()` για να λάβετε τον κωδικό νομίσματος, όπως **USD** ή **EUR**· μπορείτε στη συνέχεια να αποθηκεύσετε, καταγράψετε ή να περάσετε αυτήν την τιμή σε εξωτερικές χρηματοοικονομικές υπηρεσίες για μετατροπή. Αυτή η κλήση μίας γραμμής σας παρέχει έναν αξιόπιστο, βασισμένο σε πρότυπα αναγνωριστικό που λειτουργεί σε όλες τις υποστηριζόμενες εκδόσεις του Project.  
Η μέθοδος παρέχει έναν γρήγορο τρόπο συγχρονισμού των δεδομένων του έργου με συστήματα ERP που αναμένουν έναν τυποποιημένο κωδικό.

## Πώς να προσαρμόσετε τη μορφή νομίσματος java με Aspose.Tasks
Η αλλαγή της οπτικής αναπαράστασης των χρηματικών τιμών γίνεται μέσω τριών απλών ιδιοτήτων.

`project.setCurrencySymbol(String)` ορίζει το σύμβολο νομίσματος που εμφανίζεται για τις χρηματικές τιμές.  
`project.setCurrencyDecimalSeparator(char)` ορίζει τον χαρακτήρα που χρησιμοποιείται για το διαχωρισμό του ακέραιου μέρους από το δεκαδικό.  
`project.setCurrencyThousandsSeparator(char)` ορίζει τον χαρακτήρα που χρησιμοποιείται για το διαχωρισμό των ομάδων χιλιάδων.  

**Άμεση απάντηση:** Χρησιμοποιήστε `project.setCurrencySymbol("€")`, `project.setCurrencyDecimalSeparator(",")` και `project.setCurrencyThousandsSeparator(".")` για να ορίσετε το σύμβολο, το διαχωριστικό δεκαδικών και το διαχωριστικό χιλιάδων αντίστοιχα—αυτό αλλάζει πλήρως τη μορφή νομίσματος με μία εντολή. Η προσαρμογή αυτών των ρυθμίσεων εγγυάται ότι κάθε ενδιαφερόμενος βλέπει τους αριθμούς σε γνωστό στυλ, μειώνοντας τις παρερμηνείες.  
* `project.setCurrencySymbol("€")` – ορίζει το οπτικό σύμβολο.  
* `project.setCurrencyDecimalSeparator(",")` – ορίζει το διαχωριστικό δεκαδικών.  
* `project.setCurrencyThousandsSeparator(".")` – ορίζει το διαχωριστικό χιλιάδων.  

## Πώς να ορίσετε τις ιδιότητες νομίσματος σε έργα Aspose.Tasks
Όταν ένα έργο μεταβαίνει σε μια νέα αγορά ή ένας πελάτης ζητά διαφορετική νομισματική μορφή, θα χρειαστεί να ενημερώσετε το νόμισμα προγραμματιστικά.

`project.setCurrencyCode(String)` ορίζει τον κωδικό ISO‑4217 νομίσματος για το έργο.  

**Άμεση απάντηση:** Καλείτε `project.setCurrencyCode("GBP")` μαζί με `project.setCurrencySymbol("£")` και τα κατάλληλα διαχωριστικά, στη συνέχεια αποθηκεύστε το έργο· η βιβλιοθήκη ενημερώνει όλες τις ρυθμίσεις εμφάνισης διατηρώντας τα υπάρχοντα δεδομένα κόστους. Αυτή η προσέγγιση σας δίνει πλήρη έλεγχο πάνω στην οικονομική αναπαράσταση του χρονοδιαγράμματος σας.  

Ο οδηγός μας βήμα‑βήμα **[Setting Currency Properties in Aspose.Tasks Projects](./set-properties/)** εξηγεί πώς να:
* Ορίσετε νέο κωδικό νομίσματος και σύμβολο για ολόκληρο το έργο.  
* Προσαρμόσετε τη μορφή αριθμού (δεκαδικά ψηφία, διαχωριστικά χιλιάδων) ώστε να ταιριάζει με τις τοπικές συνήθειες.  
* Αποθηκεύσετε το ενημερωμένο αρχείο έργου χωρίς να χάσετε υπάρχοντα δεδομένα.  

Με την εξοικείωση με τον ορισμό νομίσματος, μπορείτε να εναλλάσσετε μεταξύ USD, GBP, JPY ή οποιουδήποτε υποστηριζόμενου νομίσματος άμεσα.

**Άμεση απάντηση:** Η εξοικείωση με τη διαχείριση νομίσματος σας επιτρέπει να παρουσιάζετε τα κόστη στη γλώσσα μορφοποίησης κάθε ομάδας, εξασφαλίζει ακριβείς αναφορές, συμμορφώνεται με τα περιφερειακά λογιστικά πρότυπα και επιτρέπει αυτοματοποιημένες οικονομικές ροές εργασίας—εξοικονομώντας ώρες χειροκίνητης επαναμορφοποίησης ανά έργο.  
* **Global collaboration:** Ομάδες σε διαφορετικές χώρες μπορούν να βλέπουν τα κόστη στη δική τους μορφή.  
* **Accurate reporting:** Αποτρέψτε στρογγυλοποιήσεις ή λάθη μετατροπής που θα μπορούσαν να επηρεάσουν τον προϋπολογισμό.  
* **Compliance:** Ευθυγραμμίστε με τα περιφερειακά λογιστικά πρότυπα και τις προδιαγραφές του πελάτη.  
* **Automation:** Μειώστε τις χειροκίνητες επεμβάσεις εφαρμόζοντας προγραμματιστικά τις ρυθμίσεις νομίσματος κατά τη δημιουργία του έργου.

## Συχνές ερωτήσεις

**Q: Μπορώ να αλλάξω το νόμισμα μετά την αποθήκευση του έργου;**  
A: Ναι. Χρησιμοποιήστε `Project.setCurrencyCode()` και τις σχετικές μεθόδους, στη συνέχεια αποθηκεύστε ξανά το έργο.  

**Q: Επηρεάζει η αλλαγή του νομίσματος τις υπάρχουσες τιμές κόστους;**  
A: Οι αριθμητικές τιμές παραμένουν αμετάβλητες· μόνο η μορφή εμφάνισης (σύμβολο, διαχωριστικό δεκαδικών) ενημερώνεται. Πρέπει να επαναϋπολογίσετε τα κόστη εάν χρειάζεστε μετατροπή μεταξύ νομισμάτων.  

**Q: Υπάρχουν όρια στον αριθμό των νομισμάτων που μπορώ να ορίσω;**  
A: Το Aspose.Tasks υποστηρίζει οποιονδήποτε κωδικό ISO‑4217, επομένως δεν υπάρχει πρακτικό όριο.  

**Q: Τι συμβαίνει αν ανοίξω ένα έργο με μη υποστηριζόμενο κωδικό νομίσματος;**  
A: Η βιβλιοθήκη επιστρέφει το προεπιλεγμένο νόμισμα (USD) και καταγράφει μια προειδοποίηση· μπορείτε να το παρακάμψετε ορίζοντας το επιθυμητό νόμισμα χειροκίνητα.  

**Q: Μπορεί να διαβαστούν/γραφούν οι ιδιότητες νομίσματος σε αρχείο Project XML;**  
A: Απόλυτα. Το ίδιο API λειτουργεί και για μορφές *.mpp* και *.xml*.
