# Πώς να λάβετε το σύμβολο νομίσματος java χρησιμοποιώντας το Aspose.Tasks

## Εισαγωγή
Σε αυτό το tutorial θα **get currency symbol java** και επίσης **extract currency code java** από αρχεία Microsoft Project (*.mpp*) χρησιμοποιώντας το Aspose.Tasks for Java API. Το Aspose.Tasks λειτουργεί σε οποιαδήποτε πλατφόρμα που υποστηρίζει Java, έτσι δεν χρειάζεται τοπική εγκατάσταση του Microsoft Project. Στο τέλος του οδηγού θα μπορείτε να διαβάζετε τον κωδικό ISO νομίσματος, το σύμβολο εμφάνισης, τον αριθμό των δεκαδικών ψηφίων και τη θέση του συμβόλου απευθείας από ένα αρχείο έργου, επιτρέποντάς σας να τροφοδοτείτε ακριβή μεταδεδομένα νομισματικών σε αναφορές, συστήματα ERP ή προσαρμοσμένα dashboards.

## Γρήγορες απαντήσεις
- **Τι σημαίνει “get currency symbol java”;** Σημαίνει την ανάκτηση των μεταδεδομένων που σχετίζονται με το νόμισμα (κωδικός, σύμβολο, ψηφία, θέση) από ένα αρχείο MS Project μέσω κώδικα Java.  
- **Χρειάζομαι άδεια για να το δοκιμάσω;** Διατίθεται δωρεάν δοκιμή του Aspose.Tasks· απαιτείται εμπορική άδεια για χρήση σε παραγωγή.  
- **Ποια έκδοση του JDK απαιτείται;** Java 8 ή νεότερη.  
- **Μπορώ να τροποποιήσω τις ρυθμίσεις νομίσματος μετά την ανάγνωσή τους;** Ναι, το Aspose.Tasks σας επιτρέπει τόσο την ανάγνωση όσο και την εγγραφή των ιδιοτήτων νομίσματος.  
- **Είναι συμβατό με όλες τις εκδόσεις .mpp;** Το API υποστηρίζει αρχεία που δημιουργήθηκαν με Microsoft Project 2003‑2021.

## Τι είναι το get currency symbol java;
Φορτώνοντας ένα έργο με το Aspose.Tasks και καλώντας τα κατάλληλα κλειδιά ιδιοτήτων, επιστρέφεται το σύμβολο νομίσματος που χρησιμοποιεί το αρχικό αρχείο Project. Αυτή η λειτουργία σας δίνει τον ακριβή χαρακτήρα (π.χ., `$`, `€`, `¥`) που εμφανίζεται σε αναφορές που παράγονται από το Microsoft Project. Η μέθοδος επιστρέφει τον ακριβή χαρακτήρα που χρησιμοποιείται για χρηματικές τιμές, διασφαλίζοντας ότι τυχόν παραγόμενες αναφορές ταιριάζουν με τη μορφοποίηση και τις ρυθμίσεις τοπικής γλώσσας του αρχικού έργου.

## Γιατί να διαβάζετε τις ιδιότητες νομίσματος java με το Aspose.Tasks;
Μπορείτε να ανακτήσετε τις ρυθμίσεις νομίσματος χωρίς να εκκινήσετε το Microsoft Project, κάτι που εξοικονομεί χρόνο και πόρους διακομιστή. Το Aspose.Tasks επεξεργάζεται ένα τυπικό αρχείο .mpp 200 σελίδων σε λιγότερο από 30 ms και μπορεί να διαχειριστεί αρχεία έως 500 MB χωρίς να φορτώνει ολόκληρο το έγγραφο στη μνήμη – μια ποσοτικοποιημένη δήλωση απόδοσης που καθιστά εφικτή την μαζική επεξεργασία.

2. **Aspose.Tasks for Java JAR** – κατεβάστε τη νεότερη βιβλιοθήκη Aspose.Tasks for Java από [download the latest Aspose.Tasks for Java library](https://releases.aspose.com/tasks/java/) και προσθέστε την στο classpath του έργου σας.  
3. (Optional) **License file** – ένα έγκυρο αρχείο `.lic` εάν σκοπεύετε να εκτελέσετε τον κώδικα σε περιβάλλον παραγωγής.

## Εισαγωγή πακέτων
Ξεκινήστε εισάγοντας το namespace του Aspose.Tasks που απαιτείται για τη διαχείριση του έργου:
```java
import com.aspose.tasks.*;
```

## Βήμα 1: ρυθμίστε τον φάκελο του έργου σας
Ορίστε το φάκελο που περιέχει το αρχείο `.mpp` που θέλετε να αναλύσετε. Η διατήρηση της διαδρομής σε μια μεταβλητή κάνει τον κώδικα επαναχρησιμοποιήσιμο και πιο εύκολο στη δοκιμή:
```java
String dataDir = "Your Data Directory";
```

*Αντικαταστήστε το `"Your Data Directory"` με την απόλυτη ή σχετική διαδρομή προς το φάκελο όπου βρίσκεται το `project.mpp`.*

## Βήμα 2: δημιουργήστε μια παρουσία αναγνώστη έργου
Η κλάση `Project` είναι το βασικό αντικείμενο του Aspose.Tasks που αντιπροσωπεύει ένα αρχείο Microsoft Project στη μνήμη. Η φόρτωση του αρχείου σας δίνει προγραμματιστική πρόσβαση σε κάθε ιδιότητα επιπέδου έργου, συμπεριλαμβανομένων των ρυθμίσεων νομίσματος:
```java
Project project = new Project(dataDir + "project.mpp");
```

## Βήμα 3: εμφάνιση ιδιοτήτων νομίσματος
Η απαρίθμηση `Prj` παρέχει κλειδιά για ιδιότητες έργου όπως οι ρυθμίσεις νομίσματος. Μπορείτε να ερωτήσετε κάθε κλειδί με `project.get(...)` και να μετατρέψετε το αποτέλεσμα σε αναγνώσιμο τύπο:
```java
System.out.println("Currency Code : " + project.get(Prj.CURRENCY_CODE).toString());
System.out.println("<br>Currency Digits : " + project.get(Prj.CURRENCY_DIGITS).toString());
System.out.println("<br>Currency Symbol : " + project.get(Prj.CURRENCY_SYMBOL).toString());
System.out.println("Currency Symbol Position : " + project.get(Prj.CURRENCY_SYMBOL_POSITION).toString());
```

**Τι θα δείτε:**  
- **Currency Code** – κωδικός ISO‑4217 όπως `USD`, `EUR`, `JPY`.  
- **Currency Digits** – συνήθως `2` για τα περισσότερα νομίσματα, `0` για το ιαπωνικό Yen.  
- **Currency Symbol** – ο χαρακτήρας που εμφανίζεται σε αναφορές (`$`, `€`, `¥`).  
- **Currency Symbol Position** – `0` για **πριν** το ποσό, `1` για **μετά**.

## Πώς να λάβετε το σύμβολο νομίσματος java;
Φορτώστε το έργο σας, στη συνέχεια καλέστε `project.get(Prj.CURRENCY_SYMBOL)`· η μέθοδος επιστρέφει την ακριβή συμβολοσειρά συμβόλου που χρησιμοποιείται από το αρχείο. Αυτή η μοναδική γραμμή είναι αρκετή για να τροφοδοτήσει το σύμβολο σε οποιοδήποτε downstream χρηματοοικονομικό UI ή μηχανή αναφορών. Μπορείτε στη συνέχεια να αποθηκεύσετε αυτή τη συμβολοσειρά σε μια μεταβλητή, να την καταγράψετε ή να τη μεταβιβάσετε σε άλλα στοιχεία που απαιτούν το σύμβολο νομίσματος για εμφάνιση ή υπολογισμούς.

## Βήμα 4: ολοκλήρωση διαδικασίας
Σήμα ότι η εξαγωγή ολοκληρώθηκε επιτυχώς. Αυτό το απλό μήνυμα είναι χρήσιμο όταν ο κώδικας εκτελείται ως μέρος μιας μεγαλύτερης εργασίας batch:

System.out.println("Process completed Successfully");

## Συνηθισμένα προβλήματα και λύσεις
| Πρόβλημα | Γιατί συμβαίνει | Διόρθωση |
|----------|------------------|----------|
| **FileNotFoundException** | Η διαδρομή `dataDir` είναι λανθασμένη ή το όνομα αρχείου έχει ορθογραφικό λάθος. | Επαληθεύστε τη συμβολοσειρά του καταλόγου και βεβαιωθείτε ότι το αρχείο `.mpp` υπάρχει στην καθορισμένη θέση. |
| **NullPointerException on `project.get(...)`** | Το αρχείο έργου δεν περιέχει πληροφορίες νομίσματος (σπάνιο) ή το κλειδί ιδιότητας είναι λανθασμένο. | Χρησιμοποιήστε `project.contains(Prj.CURRENCY_CODE)` για να ελέγξετε την ύπαρξη πριν την ανάγνωση. |
| **LicenseException** | Εκτέλεση χωρίς έγκυρη άδεια Aspose.Tasks σε περιβάλλον παραγωγής. | `License license = new License(); license.setLicense("Aspose.Tasks.lic");` φορτώνει το αρχείο άδειας πριν δημιουργηθεί το αντικείμενο `Project`. |
| **OutOfMemoryError on large files** | Προσπάθεια φόρτωσης πολύ μεγάλου αρχείου .mpp χωρίς streaming. | Το Aspose.Tasks επεξεργάζεται αρχεία σε λειτουργία χαμηλής μνήμης· βεβαιωθείτε ότι χρησιμοποιείτε την έκδοση 24.12 ή νεότερη. |
