Σε αυτό το σεμινάριο θα περάσουμε από όλη τη διαδικασία, από τη φόρτωση ενός αρχείου έργου μέχρι την επαλήθευση των εξαιρέσεων που διαχειριστήκατε. ## Πώς να δημιουργήσετε calendar exception java με το Aspose.Tasks
Φορτώστε το έργο, χειριστείτε το ημερολόγιό του και επαληθεύστε τις αλλαγές — όλα σε λίγα απλά βήματα που συνδυάζουν καθαρό κώδικα με σύντομες εξηγήσεις.

## Εισαγωγή πακέτων
Οι δηλώσεις `import` φέρνουν τις απαιτούμενες κλάσεις του Aspose.Tasks στο πεδίο ορατότητας ώστε να μπορούν να αναφερθούν στον κώδικα.

```java
import com.aspose.tasks.*;
```

## Βήμα 1: φόρτωση του έργου και πρόσβαση στο ημερολόγιό του
Η κλάση `Project` αντιπροσωπεύει ένα αρχείο Microsoft Project, ενώ η `Calendar` αντιπροσωπεύει ένα χρονοδιάγραμμα μέσα σε αυτό το έργο. Φορτώνουμε ένα υπάρχον αρχείο και ανακτούμε το πρώτο ημερολόγιο στη συλλογή.

```java
String dataDir = "Your Data Directory";
Project project = new Project(dataDir + "input.mpp");
Calendar cal = project.getCalendars().toList().get(0);
```

## Βήμα 2: αφαίρεση υπάρχουσας εξαίρεσης (εάν χρειάζεται)
Τα αντικείμενα `CalendarException` περιγράφουν μη‑εργατικές περιόδους. Αυτό το απόσπασμα ελέγχει τη λίστα εξαιρέσεων και αφαιρεί την πρώτη καταχώρηση όταν υπάρχει περισσότερη από μία εξαίρεση, αποτρέποντας την ακούσια αφαίρεση της μοναδικής εξαίρεσης.

```java
if (cal.getExceptions().size() > 1) {
    CalendarException exc = cal.getExceptions().get(0);
    cal.getExceptions().remove(exc);
}
```

> **Pro tip:** Πάντα ελέγχετε το μέγεθος της λίστας εξαιρέσεων πριν αφαιρέσετε στοιχεία για να αποφύγετε το `IndexOutOfBoundsException`.

## Βήμα 3: δημιουργία (προσθήκη) νέας εξαίρεσης ημερολογίου
Δημιουργούμε ένα νέο `CalendarException`, ορίζουμε τις ημερομηνίες έναρξης και λήξης, το σημειώνουμε ως μη‑εργατικό και το προσθέτουμε στη συλλογή εξαιρέσεων του ημερολογίου.

```java
CalendarException calExc = new CalendarException();
java.util.Calendar calObject = java.util.Calendar.getInstance();
calObject.set(2009, java.util.Calendar.JANUARY, 1, 0, 0, 0);
calExc.setFromDate(calObject.getTime());
calObject.set(2009, java.util.Calendar.JANUARY, 3, 0, 0, 0);
calExc.setToDate(calObject.getTime());
cal.getExceptions().add(calExc);
```

> **Why this matters:** Η προσθήκη εξαιρέσεων σας επιτρέπει να μοντελοποιήσετε διακοπές, περιόδους συντήρησης ή οποιεσδήποτε μη‑εργατικές περιόδους απευθείας στο χρονοδιάγραμμα του έργου. Αυτό αποτελεί τον πυρήνα της λειτουργικότητας **create calendar exception java**.

## Βήμα 4: εμφάνιση όλων των εξαιρέσεων για επαλήθευση
Η επανάληψη πάνω από `calendar.getExceptions()` και η εκτύπωση κάθε καταχώρησης επιβεβαιώνει ότι το ημερολόγιο αντικατοπτρίζει τις επιθυμητές αλλαγές, βοηθώντας σας να εντοπίσετε λάθη νωρίς.

```java
for (CalendarException calExc1 : cal.getExceptions()) {
    System.out.println("From " + calExc1.getFromDate().toString());
    System.out.println("To   " + calExc1.getToDate().toString());
}
```

## Πώς να προσθέσω μια εξαίρεση ημερολογίου σε Java;
Φορτώστε το έργο σας με `new Project("input.mpp")`, ανακτήστε το στόχο `Calendar`, δημιουργήστε ένα `CalendarException` με τις επιθυμητές ημερομηνίες έναρξης και λήξης, ορίστε τη σημαία εργασίας του σε `false` και προσθέστε το στο `calendar.getExceptions()`. Αυτή η σύντομη ακολουθία δημιουργεί μια calendar exception java με λίγες μόνο γραμμές κώδικα.
