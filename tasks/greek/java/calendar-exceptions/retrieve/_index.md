## Εισαγωγή πακέτων
Οι δηλώσεις εισαγωγής φέρνουν τις κλάσεις Aspose.Tasks στο αρχείο πηγαίου κώδικα Java, επιτρέποντάς σας να εργάζεστε με έργα, ημερολόγια και εξαιρέσεις.

```java
import com.aspose.tasks.*;
import java.util.*;
```

## Βήμα 1: ρύθμιση του καταλόγου δεδομένων
Ορίστε έναν φάκελο που περιέχει το αρχείο Project που θέλετε να αναλύσετε. Η χρήση απόλυτης διαδρομής ή διαδρομής σχετικής με το φάκελο πόρων του έργου σας αποτρέπει το `FileNotFoundException`.

```java
String dataDir = "C:/Projects/Data/";
```

> **Συμβουλή:** Αποθηκεύστε τα αρχεία Project σε έναν αφιερωμένο φάκελο πόρων και αναφερθείτε σε αυτά με `Paths.get(...)` για διαδρομές ανεξάρτητες από την πλατφόρμα.

## Βήμα 2: φόρτωση αρχείου ms project
Η κλάση `Project` αντιπροσωπεύει ένα αρχείο MS Project και παρέχει πρόσβαση στα ημερολόγια, τις εργασίες, τους πόρους και άλλα δεδομένα του έργου. Φορτώστε το αρχείο Project σε ένα αντικείμενο `Project`. Αυτό το αντικείμενο αντιπροσωπεύει ολόκληρο το αρχείο MS Project στη μνήμη και παρέχει πρόσβαση σε ημερολόγια, εργασίες, πόρους κ.ά.

```java
Project project = new Project(dataDir + "project.mpp");
```

## Βήμα 3: ανάκτηση εξαιρέσεων ημερολογίου
Διατρέξτε κάθε ημερολόγιο στο έργο και, στη συνέχεια, κάθε εξαίρεση ημερολογίου μέσα σε αυτό το ημερολόγιο. Εκτυπώστε τις ημερομηνίες έναρξης και λήξης κάθε εξαίρεσης.

```java
for (Calendar cal : project.getCalendars()) {
    for (CalendarException calExc : cal.getExceptions()) {
        System.out.println("Exception from " + calExc.getFromDate() + " to " + calExc.getToDate());
    }
}
```

## Συχνά προβλήματα και λύσεις
| Πρόβλημα | Αιτία | Διόρθωση |
|----------|-------|----------|
| **Δεν εμφανίζεται έξοδος** | Το αρχείο Project δεν περιέχει εξαιρέσεις ημερολογίου. | Επαληθεύστε ότι το ημερολόγιο στο MS Project έχει ορισμένες εξαιρέσεις (π.χ., διακοπές). |
| **`NullPointerException`** | Η διαδρομή `dataDir` είναι λανθασμένη ή το αρχείο δεν βρέθηκε. | Ελέγξτε ξανά τη διαδρομή του καταλόγου και βεβαιωθείτε ότι το `project.mpp` υπάρχει. |
| **Ασυμφωνία ζώνης ώρας** | Οι ημερομηνίες εμφανίζονται σε UTC. | Χρησιμοποιήστε `calExc.getFromDate().toLocalDateTime()` για μετατροπή στην τοπική ώρα, εάν χρειάζεται. |
