# Πώς να προσθέσετε ημερολόγιο αργιών και να καθορίσετε εργάσιμες ημέρες

Η διαχείριση των ημερολογίων έργου αποτελεί βασικό μέρος της επιτυχημένης προγραμματισμού έργου. Σε αυτό το tutorial θα **προσθέσετε ημερολόγιο αργιών**, **καθορίσετε εργάσιμες ημέρες** για οποιαδήποτε εργασία, και **εξάγετε ώρες εργασίας** από ένα ημερολόγιο MS Project χρησιμοποιώντας το Aspose.Tasks for Java. Στο τέλος του οδηγού θα μπορείτε να **υπολογίσετε τη διάρκεια της εργασίας**, να προσαρμόσετε τις ώρες εργασίας, και αξιόπιστα **φορτώσετε ένα αρχείο MPP** για να ανακτήσετε τα δεδομένα που χρειάζεστε — χωρίς την εγκατάσταση του Microsoft Project.

## Σύντομες απαντήσεις
- **Τι σημαίνει “determine working days”;** Σημαίνει την ταυτοποίηση των ημερομηνιών του ημερολογίου που θεωρούνται εργάσιμες ημέρες για μια δεδομένη εργασία.  
- **Ποια βιβλιοθήκη πρέπει να χρησιμοποιήσω;** Το Aspose.Tasks for Java παρέχει ένα πλήρες API για εργασία με αρχεία MS Project.  
- **Πόσο διαρκεί η υλοποίηση;** Συνήθως 10–15 λεπτά για μια βασική εξαγωγή.  
- **Χρειάζομαι άδεια;** Διατίθεται δωρεάν δοκιμαστική έκδοση· απαιτείται εμπορική άδεια για παραγωγική χρήση.  
- **Μπορώ να προσαρμόσω τις ώρες εργασίας;** Ναι – μπορείτε να τροποποιήσετε τα ημερολόγια, να προσθέσετε αργίες και να ορίσετε προσαρμοσμένα χρονικά διαστήματα εργασίας.  

## Τι είναι το “determine working days”;
**Determine working days** σημαίνει την ερώτηση ενός ημερολογίου έργου για το ποιες ημερομηνίες είναι σημειωμένες ως εργάσιμες ημέρες σε αντίθεση με μη εργάσιμες ημέρες (Σαββατοκύριακα, αργίες ή προσαρμοσμένες εξαιρέσεις). Αυτές οι πληροφορίες είναι απαραίτητες για ακριβή **calculate task duration** επειδή μόνο οι εργάσιμες ημέρες συμβάλλουν στον συνολικό χρόνο μιας εργασίας.

## Γιατί να χρησιμοποιήσετε το Aspose.Tasks για την ανάκτηση ωρών εργασίας;
Το Aspose.Tasks σας επιτρέπει να διαβάζετε αρχεία MS Project χωρίς να είναι εγκατεστημένο το Microsoft Project, επιτρέποντας αυτοματοποίηση σε οποιαδήποτε πλατφόρμα. Παρέχει επίσης επεξεργασία υψηλής απόδοσης, εκτενή υποστήριξη μορφών και λεπτομερή τεκμηρίωση.  

- **Full calendar support** – τα προεπιλεγμένα, πόρων και ημερολόγια εργασιών είναι όλα προσβάσιμα.  
- **High performance** – μπορεί να επεξεργαστεί έργα που περιέχουν **10.000+ εργασίες σε λιγότερο από 2 δευτερόλεπτα** σε μια τυπική CPU 2.5 GHz.  
- **Extensive format coverage** – υποστηρίζει **50+ μορφές εισόδου και εξόδου**, συμπεριλαμβανομένων των MPP, MPX, XML και Primavera.  
- **Comprehensive documentation** – δείγματα κώδικα, αναφορά API και φόρουμ κοινότητας είναι όλα διαθέσιμα.

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

1. **Java Development Kit (JDK)** – έκδοση 8 ή νεότερη.

## Εισαγωγή πακέτων
Η κλάση `Project` είναι το κορυφαίο αντικείμενο του Aspose.Tasks που αντιπροσωπεύει ένα μόνο αρχείο MS Project στη μνήμη. Εισάγετε το απαιτούμενο namespace πριν ξεκινήσετε:

Εισαγωγή Πακέτων

```java
import com.aspose.tasks.*;
```

## Πώς να φορτώσετε ένα αρχείο MPP με το Aspose.Tasks;
Η κλάση `Project` φορτώνει ένα αρχείο MS Project και παρέχει πρόσβαση στα δεδομένα του. Φορτώστε το αρχείο έργου με μια μόνο γραμμή κώδικα· δεν απαιτείται UI ή COM interop. Αυτό το απλό βήμα σας δίνει πλήρη πρόσβαση σε ημερολόγια, εργασίες και πόρους.

Φόρτωση αρχείου MPP

```java
String dataDir = "Your Data Directory";
Project project = new Project(dataDir + "project.mpp");
```

## Ανάκτηση πληροφοριών εργασίας και ημερολογίου
`Task` αντιπροσωπεύει μια εργασία του έργου, και `Calendar` ορίζει τους κανόνες χρόνου εργασίας του. Επιλέξτε την εργασία που θέλετε να αναλύσετε και λάβετε το σχετικό ημερολόγιο. Το αντικείμενο `Task` παρέχει τις μεθόδους `getStart()` και `getFinish()`, ενώ το αντικείμενο `Calendar` εκθέτει τους ορισμούς χρόνου εργασίας.

Ανάκτηση εργασίας και ημερολογίου

```java
Task task = project.getRootTask().getChildren().getById(1);
Calendar taskCalendar = task.get(Tsk.CALENDAR);
```

## Ορισμός ημερομηνιών έναρξης και λήξης
Τα αντικείμενα `Date` καθορίζουν το χρονικό παράθυρο για την ανάλυση του ημερολογίου. Ορίστε το χρονικό παράθυρο για το οποίο θέλετε να **determine working days**. Η χρήση των ημερομηνιών έναρξης και λήξης της εργασίας εξασφαλίζει ότι αξιολογείτε μόνο τη σχετική περίοδο.

Ορισμός ημερομηνιών

```java
java.util.Calendar calStartDate = java.util.Calendar.getInstance();
calStartDate.setTime(task.get(Tsk.START));
java.util.Calendar calEndDate = java.util.Calendar.getInstance();
calEndDate.setTime(task.get(Tsk.FINISH));
```

## Επανάληψη μέσω ημερομηνιών
Ένας βρόχος `for` μπορεί να επαναλάβει κάθε ημέρα στο εύρος ημερομηνιών. Επανάληψη μέσω κάθε ημερομηνίας στη διάρκεια της εργασίας. Αυτός ο βρόχος θα σας επιτρέψει να **customize working hours** αργότερα αν χρειαστεί και αποτελεί τη βάση για τον υπολογισμό του συνολικού χρόνου εργασίας.

Επανάληψη ημερομηνιών

```java
java.util.Calendar tempDate = calStartDate;
```

## Υπολογισμός διάρκειας
`Duration` συγκεντρώνει το συνολικό χρόνο εργασίας που υπολογίζεται από την επανάληψη. Κατά τη διάρκεια της επανάληψης ελέγχετε αν κάθε ημέρα είναι εργάσιμη, αθροίζετε τις ώρες εργασίας και τελικά υπολογίζετε τη διάρκεια της εργασίας σε λεπτά, ώρες και ημέρες. Αυτό δείχνει πώς να **calculate working days** και **calculate task duration** προγραμματιστικά.

Υπολογισμός διάρκειας

```java
double durationInMins = 0;
double durationInHours = 0;
double durationInDays = 0;
long OneSec = 10000000;
long OneMin = 60 * OneSec;
long OneHour = 60 * OneMin;
long timeSpan;
while (tempDate.before(calEndDate)) {
    if (taskCalendar.isDayWorking(tempDate.getTime())) {
        timeSpan = (long) taskCalendar.getWorkingHours(tempDate.getTime());
        durationInMins += (double) timeSpan / OneMin;
        durationInHours += (double) timeSpan / OneHour;
        if ((timeSpan / OneHour) > 0) {
            durationInDays += ((double) timeSpan / OneHour / 8.0);
        }
    }
    tempDate.add(java.util.Calendar.DATE, 1);
}
System.out.println("Duration in Minutes = " + durationInMins);
System.out.println("Duration in Hours = " + durationInHours);
System.out.println("Duration in Days = " + durationInDays);
System.out.println();
```

## Πώς να προσαρμόσετε τις ώρες εργασίας και τις αργίες
Μπορείτε να τροποποιήσετε τα χρονικά διαστήματα εργασίας του ημερολογίου και να προσθέσετε εξαιρέσεις όπως αργίες. Χρησιμοποιήστε `taskCalendar.addWorkingTime()` για να ορίσετε νέες περιόδους εργασίας και `taskCalendar.addException()` για να εισάγετε μια αργία. Αυτό είναι χρήσιμο όταν το προεπιλεγμένο πρόγραμμα 9‑5 δεν ταιριάζει με τις πολιτικές του οργανισμού σας.

| **Λανθασμένη διάρκεια λόγω αργιών** | Επαληθεύστε ότι οι αργίες ορίζονται στο ημερολόγιο της εργασίας ή στο βασικό ημερολόγιο του έργου. |
| **Ασυμφωνία ζώνης ώρας** | Χρησιμοποιήστε το `java.util.TimeZone` για να ευθυγραμμίσετε τη ζώνη ώρας του ημερολογίου με το σύστημά σας εάν χρειάζεται. |
