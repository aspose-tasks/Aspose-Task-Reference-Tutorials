# Ημερολόγια

## Εισαγωγή

Αν είστε προγραμματιστής Java που θέλει να **δημιουργήσει προσαρμοσμένα ημερολόγια Java** λύσεις, βρίσκεστε στο σωστό μέρος. Αυτό το κέντρο συγκεντρώνει όλα τα Aspose.Tasks for Java tutorials που δείχνουν πώς να **ορίσετε εργάσιμες ημέρες MS Project**, **ορίσετε εργάσιες ώρες MS Project**, και να προγραμματιστικά προσαρμόσετε τις ρυθμίσεις του ημερολογίου. Είτε δημιουργείτε μια νέα μηχανή χρονοπρογραμματισμού είτε επεκτείνετε ένα υπάρχον σχέδιο, η εξοικείωση με αυτά τα APIs σας δίνει ακριβή έλεγχο στα πρότυπα των εργάσιμων ημερών, τις αργίες και τις προσαρμοσμένες βάρδιες—χωρίς ποτέ να ανοίξετε το UI του MS Project.

## Γρήγορες απαντήσεις
- **Ποιος είναι ο κύριος σκοπός του ορισμού των εργάσιμων ημερών;**  
  Να ενημερώσετε το MS Project ποιες ημέρες είναι εργάσιμες και ποιες είναι οι εργάσιμες ώρες τους.  
- **Ποια βιβλιοθήκη διαχειρίζεται τον ορισμό των εργάσιμων ημερών σε Java;**  
  Το Aspose.Tasks for Java παρέχει ένα fluent API για τη διαχείριση ημερολογίων.  
- **Χρειάζομαι άδεια;**  
  Μια δωρεάν άδεια αξιολόγησης λειτουργεί για δοκιμές· απαιτείται εμπορική άδεια για παραγωγή.  
- **Μπορώ να ορίσω πολλαπλά ημερολόγια για διαφορετικές ομάδες;**  
  Ναι – κάθε έργο μπορεί να περιέχει πολλά ημερολόγια, καθένα με τις δικές του ρυθμίσεις εργάσιμων ημερών.  
- **Υπάρχει δείγμα έργου για εκκίνηση;**  
  Το tutorial “Define Weekdays in Calendar” που συνδέεται παρακάτω περιλαμβάνει ένα έτοιμο παράδειγμα.

## Πώς να δημιουργήσετε προσαρμοσμένο ημερολόγιο Java;

Φορτώστε ένα έργο, δημιουργήστε ή ανακτήστε ένα ημερολόγιο, προσθέστε ορισμούς εργάσιμων ημερών και αποθηκεύστε το αρχείο—όλα με μερικές κλήσεις API. Αυτή η προσέγγιση αφαιρεί τα χειροκίνητα βήματα UI, σας επιτρέπει να αυτοματοποιήσετε τη δημιουργία ημερολογίων σε δεκάδες έργα και εξασφαλίζει συνεπή πρότυπα εργάσιμων ημερών σε όλη την οργάνωση.

## Τι είναι η κλάση Project;

Η κλάση `Project` είναι το κεντρικό αντικείμενο για τη φόρτωση, επεξεργασία και αποθήκευση αρχείων MS Project. Διατηρεί συλλογές εργασιών, πόρων και ημερολογίων, εκθέτοντας μεθόδους που σας επιτρέπουν να διαβάζετε και να τροποποιείτε κάθε πτυχή ενός έργου προγραμματιστικά. Χρησιμοποιώντας αυτήν την κλάση, μπορείτε να έχετε πρόσβαση στη συλλογή ημερολογίων του έργου, να προσαρμόζετε τις εργάσιμες ώρες και να αποθηκεύετε τις αλλαγές πίσω σε αρχείο MPP ή XML.

## Πώς ορίζω τις εργάσιμες ημέρες στα ημερολόγια MS Project;

Η κλάση `Project` αντιπροσωπεύει ένα αρχείο MS Project και παρέχει πρόσβαση στις δομές δεδομένων του. Ένα αντικείμενο `Calendar` αποθηκεύει ορισμούς εργάσιμων ωρών και εξαιρέσεων για ένα έργο. Φορτώστε το έργο σας με `new Project("myproject.mpp")`, ανακτήστε (ή δημιουργήστε) ένα αντικείμενο `Calendar`, και στη συνέχεια καλέστε `calendar.getWeekDays().add(new WeekDay(DayType.Monday, true, new WorkingTime(9, 0, 17, 0)))`. Αυτή η εντολή δημιουργεί μια καταχώρηση εργάσιμης ημέρας για τη Δευτέρα με βάρδια 8 ωρών. Επαναλάβετε για τις άλλες ημέρες και, τέλος, αποθηκεύστε το έργο με `project.save("updated.mpp")`. Αυτό το σύντομο μοτίβο σας επιτρέπει να ορίζετε, να τροποποιείτε ή να διαγράφετε εργάσιμες ημέρες με λίγες κλήσεις API, εξαλείφοντας την ανάγκη χειροκίνητης αλληλεπίδρασης με το UI.

## Τι είναι το αντικείμενο WeekDay;

Ένα αντικείμενο `WeekDay` αντιπροσωπεύει μια μοναδική καταχώρηση ημέρας της εβδομάδας μέσα σε ένα ημερολόγιο. Αποθηκεύει αν η ημέρα είναι εργάσιμη, τα διαστήματα εργάσιμων ωρών για εκείνη την ημέρα και σημαίες για προεπιλεγμένη συμπεριφορά. Μπορείτε να συσχετίσετε ένα ή περισσότερα διαστήματα `WorkingTime` για να μοντελοποιήσετε διπλές βάρδιες, να ορίσετε την ημέρα ως μη εργάσιμη ή να κληρονομήσετε τις προεπιλογές από το γονικό ημερολόγιο.

## Πώς να ορίσετε εργάσιμες ημέρες MS Project;

Ορίζετε εργάσιμες ημέρες προσθέτοντας αντικείμενα `WeekDay` στη συλλογή `WeekDays` ενός ημερολογίου. Κάθε `WeekDay` καθορίζει αν η ημέρα είναι εργάσιμη και τα χρονικά διαστήματα που θεωρούνται εργάσιμα. Για παράδειγμα, για να κάνετε το Σάββατο μισή ημέρα, προσθέστε ένα `WeekDay` με ένα μοναδικό `WorkingTime` από 10:00 έως 14:00. Το API ενημερώνει αυτόματα τους υπολογισμούς χρονοδιαγράμματος του έργου.

## Πώς να ορίσετε εργάσιες ώρες MS Project;

Ορίστε εργάσιες ώρες δημιουργώντας ένα ή περισσότερα διαστήματα `WorkingTime` για κάθε `WeekDay`. Ένα `WorkingTime` δέχεται τιμές ώρας έναρξης, λεπτών έναρξης, ώρας λήξης και λεπτών λήξης. Μπορείτε να αναθέσετε πολλαπλά διαστήματα σε μία ημέρα για να μοντελοποιήσετε διπλές βάρδιες (π.χ. 08:00‑12:00 και 13:00‑17:00). Αφού διαμορφώσετε όλες τις εργάσιμες ημέρες, καλέστε `project.save(...)` για να αποθηκεύσετε τις αλλαγές.

## Συχνές ερωτήσεις

**Q:** Μπορώ να ορίσω διαφορετικές εργάσιμες ώρες για κάθε εργάσιμη ημέρα;  
**A:** Ναι. Το Aspose.Tasks σας επιτρέπει να ορίσετε ξεχωριστές ώρες έναρξης και λήξης για τη Δευτέρα έως την Κυριακή.

**Q:** Πώς διαχειρίζομαι αργίες ή μη εργάσιμες ημέρες;  
**A:** Αφού ορίσετε τις εργάσιμες ημέρες, μπορείτε να προσθέσετε εξαιρέσεις (ημερομηνίες) για να σημειώσετε αργίες ή προσαρμοσμένες μη εργάσιμες περιόδους.

**Q:** Είναι δυνατόν να αντιγράψω έναν ορισμό εργάσιμης ημέρας από ένα ημερολόγιο σε άλλο;  
**A:** Απόλυτα. Μπορείτε να ανακτήσετε ένα αντικείμενο `WeekDay` από ένα υπάρχον ημερολόγιο και να το προσθέσετε σε άλλο ημερολόγιο.

**Q:** Πρέπει να επαναφορτώσω το έργο μετά την ενημέρωση των εργάσιμων ημερών;  
**A:** Όχι. Οι αλλαγές εφαρμόζονται απευθείας στο αντικείμενο `Project` στη μνήμη· απλώς αποθηκεύστε το έργο όταν τελειώσετε.

**Q:** Ποια έκδοση του Aspose.Tasks απαιτείται για τη διαχείριση των εργάσιμων ημερών;  
**A:** Όλες οι πρόσφατες εκδόσεις (20.10 και μετά) υποστηρίζουν πλήρη API εργάσιμων ημερών. Συνιστούμε τη χρήση της τελευταίας σταθερής έκδοσης για βέλτιστη απόδοση.
