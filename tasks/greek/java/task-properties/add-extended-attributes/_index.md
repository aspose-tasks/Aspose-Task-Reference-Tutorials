# Πώς να δημιουργήσετε εκτεταμένο χαρακτηριστικό εργασίας με το Aspose.Tasks για Java

## Εισαγωγή
Σε αυτό το μάθημα θα μάθετε πώς να **δημιουργήσετε εκτεταμένο χαρακτηριστικό εργασίας** σε ένα αρχείο Microsoft Project χρησιμοποιώντας το Aspose.Tasks για Java. Η προσθήκη προσαρμοσμένων πεδίων σας επιτρέπει να καταγράψετε δεδομένα ειδικά για το έργο που δεν καλύπτονται από τις ενσωματωμένες στήλες, παρέχοντάς σας πιο λεπτομερή έλεγχο στην αναφορά και τον προγραμματισμό πόρων. Στο τέλος του οδηγού θα μπορείτε να προσθέσετε χαρακτηριστικά κειμένου, με δυνατότητα αναζήτησης και διάρκειας σε οποιαδήποτε εργασία.

## Σύντομες απαντήσεις
- **Τι σημαίνει “εκτεταμένο χαρακτηριστικό”;** Είναι ένα προσαρμοσμένο πεδίο που ορίζετε και συνδέετε με εργασίες, πόρους ή εκχωρήσεις.  
- **Ποια βιβλιοθήκη προσθέτει αυτή τη δυνατότητα;** Aspose.Tasks για Java, μια βιβλιοθήκη διαχείρισης έργων σε Java.  
- **Χρειάζομαι άδεια για δοκιμή;** Ναι – υπάρχει δωρεάν δοκιμαστική έκδοση 30 ημερών διαθέσιμη από την ιστοσελίδα Aspose.  
- **Μπορώ να προσθέσω τιμές αναζήτησης;** Απόλυτα· μπορείτε να παρέχετε μια λίστα επιτρεπόμενων τιμών για πεδία κειμένου ή διάρκειας.  
- **Είναι το API συμβατό με Java 8 και νεότερες εκδόσεις;** Ναι, υποστηρίζει Java 8+ και λειτουργεί σε όλα τα κύρια λειτουργικά συστήματα.

## Τι είναι ένα εκτεταμένο χαρακτηριστικό εργασίας;
Ένα εκτεταμένο χαρακτηριστικό εργασίας είναι μια στήλη που ορίζεται από τον χρήστη και αποθηκεύει πρόσθετες πληροφορίες για κάθε εργασία σε ένα αρχείο Project. Συμπεριφέρεται όπως ένα ενσωματωμένο πεδίο, αλλά μπορεί να περιέχει οποιονδήποτε τύπο δεδομένων χρειάζεστε, όπως κείμενο, αριθμούς, ημερομηνίες ή διάρκειες.

## Γιατί να χρησιμοποιήσετε το Aspose.Tasks για Java;
Το Aspose.Tasks υποστηρίζει **πάνω από 50 μορφές αρχείων** και μπορεί να επεξεργαστεί έργα με **πάνω από 10.000 εργασίες** χωρίς να απαιτείται εγκατάσταση του Microsoft Project. Η βιβλιοθήκη λειτουργεί πλήρως offline, εξασφαλίζοντας ιδιωτικότητα δεδομένων και προβλέψιμη απόδοση για λύσεις επιχειρησιακού μεγέθους.

## Προαπαιτούμενα
Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε:

- Βασικές γνώσεις προγραμματισμού Java.  
- Τη βιβλιοθήκη Aspose.Tasks για Java εγκατεστημένη. Μπορείτε να τη κατεβάσετε από την [website](https://releases.aspose.com/tasks/java/).  
- Ένα IDE Java (IntelliJ IDEA, Eclipse ή VS Code) ρυθμισμένο στον υπολογιστή σας.

## Εισαγωγή πακέτων
Οι δηλώσεις `import` σας δίνουν πρόσβαση στις βασικές κλάσεις που θα χρειαστείτε, όπως `Project`, `ExtendedAttributeDefinition` και `ExtendedAttribute`.  

`Project` αντιπροσωπεύει ένα αρχείο Microsoft Project και παρέχει μεθόδους για ανάγνωση, τροποποίηση και αποθήκευση.  
`ExtendedAttributeDefinition` ορίζει ένα προσαρμοσμένο πεδίο που μπορεί να προσαρτηθεί σε εργασίες, πόρους ή εκχωρήσεις.  
`ExtendedAttribute` είναι μια παρουσία ενός ορισμού που κρατά την πραγματική τιμή για μια συγκεκριμένη οντότητα.

## Πώς να προσθέσετε ένα εκτεταμένο χαρακτηριστικό απλού κειμένου σε μια εργασία;
Για να προσθέσετε ένα εκτεταμένο χαρακτηριστικό απλού κειμένου, πρώτα φορτώνετε το έργο, δημιουργείτε έναν ορισμό τύπου Text, τον προσθέτετε στη συλλογή του έργου, δημιουργείτε μια εργασία, δημιουργείτε το χαρακτηριστικό από τον ορισμό, ορίζετε την τιμή κειμένου, το συνδέετε με την εργασία και τέλος αποθηκεύετε το έργο.

### 1. Ορίστε τη διαδρομή του φακέλου εγγράφου
Καθορίστε πού βρίσκονται τα αρχεία πηγής και εξόδου.

```java
import java.io.IOException;
import com.aspose.tasks.*;
```

### 2. Δημιουργήστε ένα νέο έργο
Δημιουργήστε ένα αντικείμενο `Project`, προαιρετικά φορτώνοντας ένα υπάρχον αρχείο .mpp.

```java
String dataDir = "Your Document Directory";
```

### 3. Δημιουργήστε έναν ορισμό εκτεταμένου χαρακτηριστικού τύπου Text1
Ορίστε το προσαρμοσμένο πεδίο ως στήλη απλού κειμένου με όνομα “Text1”.

```java
Project project = new Project(dataDir + "project.mpp");
```

### 4. Προσθέστε τον ορισμό στη συλλογή εκτεταμένων χαρακτηριστικών του έργου
Καταχωρίστε τον νέο ορισμό ώστε το έργο να τον αναγνωρίζει.

```java
ExtendedAttributeDefinition taskExtendedAttributeText1Definition = ExtendedAttributeDefinition.createTaskDefinition(CustomFieldType.Text, ExtendedAttributeTask.Text1, "Task City Name");
```

### 5. Προσθέστε μια εργασία στο έργο
Δημιουργήστε μια εργασία που θα λάβει το προσαρμοσμένο πεδίο.

```java
project.getExtendedAttributes().add(taskExtendedAttributeText1Definition);
```

### 6. Δημιουργήστε ένα εκτεταμένο χαρακτηριστικό από τον ορισμό χαρακτηριστικού
Δημιουργήστε μια παρουσία που μπορείτε να συνδέσετε με μια συγκεκριμένη εργασία.

```java
Task task = project.getRootTask().getChildren().add("Task 1");
```

### 7. Εκχωρήστε μια τιμή στο παραγόμενο εκτεταμένο χαρακτηριστικό
Ορίστε το πραγματικό κείμενο που θέλετε να αποθηκεύσετε, π.χ., “Design Review”.

```java
ExtendedAttribute taskExtendedAttributeText1 = taskExtendedAttributeText1Definition.createExtendedAttribute();
```

### 8. Προσθέστε το εκτεταμένο χαρακτηριστικό στην εργασία
Συνδέστε την παρουσία του χαρακτηριστικού με τη συλλογή `ExtendedAttributes` της εργασίας.

```java
taskExtendedAttributeText1.setTextValue("London");
```

### 9. Αποθηκεύστε το έργο
Γράψτε το ενημερωμένο έργο πίσω στο δίσκο στη ζητούμενη μορφή.

```java
task.getExtendedAttributes().add(taskExtendedAttributeText1);
```

## Πώς να προσθέσετε ένα χαρακτηριστικό κειμένου με επιλογή αναζήτησης;
Κατά την προσθήκη ενός χαρακτηριστικού κειμένου με αναζήτηση, ακολουθείτε τα ίδια βήματα όπως για το χαρακτηριστικό απλού κειμένου, αλλά πριν προσθέσετε τον ορισμό, γεμίζετε τη συλλογή `LookupValues` με τις επιτρεπόμενες συμβολοσειρές. Αυτές οι τιμές εμφανίζονται ως αναπτυσσόμενη λίστα στο Microsoft Project, εξασφαλίζοντας συνέπεια δεδομένων.

## Πώς να προσθέσετε ένα χαρακτηριστικό διάρκειας με επιλογή αναζήτησης;
Για να προσθέσετε ένα χαρακτηριστικό διάρκειας με αναζήτηση, αντικαταστήστε τον τύπο `Text1` με `Duration2` κατά τη δημιουργία του ορισμού, στη συνέχεια γεμίστε τη συλλογή `LookupValues` με συμβολοσειρές διάρκειας όπως “1 day”, “2 days” κ.λπ. Αφού ο ορισμός προστεθεί στο έργο, δημιουργήστε την παρουσία του χαρακτηριστικού, ορίστε μια τιμή διάρκειας, συνδέστε το με μια εργασία και αποθηκεύστε το αρχείο.

## Συχνά προβλήματα και αντιμετώπιση
- **Lookup values not appearing** – Βεβαιωθείτε ότι προσθέτετε κάθε καταχώρηση αναζήτησης στη συλλογή `LookupValues` *πριν* καλέσετε `project.getExtendedAttributes().add(definition)`.  
- **Attribute value not saved** – Επαληθεύστε ότι προσθέτετε την παρουσία `ExtendedAttribute` στην εργασία *μετά* τον ορισμό της τιμής.  
- **File size grows unexpectedly** – Όταν εργάζεστε με πολύ μεγάλα έργα, σκεφτείτε να καλέσετε `project.setSaveOptions(new ProjectSaveOptions())` για ενεργοποίηση της σταδιακής αποθήκευσης.
