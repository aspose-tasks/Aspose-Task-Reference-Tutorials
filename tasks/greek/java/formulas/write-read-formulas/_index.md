# Πώς να δημιουργήσετε προσαρμοσμένο πεδίο aspose και να αποθηκεύσετε αρχείο έργου

## Εισαγωγή
Σε αυτό το tutorial θα δείτε ένα **custom field formula example** που δείχνει πώς να **save a project file**, να γράψετε και να διαβάσετε τύπους MS Project, και να εφαρμόσετε έναν **double task cost formula** χρησιμοποιώντας το Aspose.Tasks for Java. Στο τέλος θα καταλάβετε γιατί τα προσαρμοσμένα πεδία είναι ισχυρά, πώς να ενσωματώσετε υπολογισμούς απευθείας σε ένα έργο, και πώς να διατηρήσετε αυτές τις αλλαγές για μελλοντική αναφορά. Η κύρια εστίαση είναι στο **create custom field aspose** ώστε να μπορείτε να αυτοματοποιήσετε τους υπολογισμούς κόστους σε οποιαδήποτε ροή εργασίας βασισμένη σε MS Project.

## Γρήγορες απαντήσεις
- **Τι κάνει η “save project file”;** Γράφει όλες τις αλλαγές στη μνήμη πίσω σε ένα αρχείο .mpp στο δίσκο.  
- **Μπορώ να προσθέσω τύπους προσαρμοσμένων πεδίων;** Ναι – μπορείτε να δημιουργήσετε ένα προσαρμοσμένο πεδίο και να ορίσετε έναν τύπο όπως “double task cost”.  
- **Χρειάζομαι άδεια για να εκτελέσω τον κώδικα;** Μια δωρεάν δοκιμή λειτουργεί για αξιολόγηση· απαιτείται εμπορική άδεια για παραγωγή.  
- **Ποιο IDE λειτουργεί καλύτερα;** Οποιοδήποτε Java IDE (IntelliJ IDEA, Eclipse, VS Code) θα μεταγλωττίσει το παράδειγμα.  
- **Είναι το API συμβατό με την τελευταία έκδοση του MS Project;** Το Aspose.Tasks υποστηρίζει όλες τις πρόσφατες μορφές .mpp.

## Τι είναι το “save project file” στο Aspose.Tasks;
Η αποθήκευση ενός αρχείου έργου σημαίνει τη διατήρηση της τρέχουσας κατάστασης του αντικειμένου `Project` — συμπεριλαμβανομένων των εργασιών, των πόρων και τυχόν προσαρμοσμένων τύπων — σε ένα φυσικό αρχείο Microsoft Project (`.mpp`). Αυτή η λειτουργία είναι απαραίτητη μετά την τροποποίηση δεδομένων, όπως η προσθήκη προσαρμοσμένου πεδίου ή η αλλαγή του κόστους εργασιών. Η κλήση `save` γράφει ολόκληρη τη δομή του έργου στο δίσκο, καθιστώντας τις αλλαγές διαθέσιμες για εργαλεία αναφοράς downstream.

## Γιατί να προσθέσετε ένα προσαρμοσμένο πεδίο και να δημιουργήσετε τύπο προσαρμοσμένου πεδίου;
Προσθέτετε ένα προσαρμοσμένο πεδίο όταν χρειάζεται να αποθηκεύσετε πληροφορίες που δεν καλύπτονται από τα ενσωματωμένα πεδία. Η προσθήκη τύπου—όπως ένας **double task cost**—αυτοματοποιεί τους υπολογισμούς, εξαλείφει τις χειροκίνητες ενημερώσεις και εγγυάται ότι κάθε φορά που αλλάζει το βασικό κόστος, η παράγωγη τιμή ενημερώνεται αμέσως. Αυτή η προσέγγιση μειώνει τα σφάλματα και διατηρεί τα δεδομένα του χρονοδιαγράμματος συνεπή μεταξύ των ομάδων.

## Προαπαιτούμενα
1. **Java Development Kit (JDK)** – Java 8 ή νεότερο εγκατεστημένο στο μηχάνημά σας.  
2. **Aspose.Tasks for Java** – Κατεβάστε και εγκαταστήστε από τη [Aspose.Tasks Java download page](https://releases.aspose.com/tasks/java/).  
3. **Integrated Development Environment (IDE)** – Επιλέξτε το προτιμώμενο IDE σας για ανάπτυξη Java (IntelliJ IDEA, Eclipse, VS Code, κ.λπ.).  

## Εισαγωγή πακέτων
Οι κλάσεις `Project`, `ExtendedAttribute` και σχετικές βρίσκονται στο namespace `com.aspose.tasks`. Εισάγετέ τες στην αρχή του αρχείου πηγαίου κώδικα ώστε ο μεταγλωττιστής να μπορεί να επιλύσει τους τύπους.

```java
import com.aspose.tasks.*;
import java.io.IOException;
import java.math.BigDecimal;
import java.util.Objects;
```

## Βήμα 1: ρύθμιση καταλόγου δεδομένων
Ορίστε το φάκελο όπου βρίσκονται τα αρχεία MS Project σας. Εδώ θα φορτώσετε το αρχείο προέλευσης και αργότερα **save project file**.

```java
// The path to the documents directory.
String dataDir = "Your Data Directory";
```

## Βήμα 2: φόρτωση αρχείου έργου
Η κλάση `Project` αντιπροσωπεύει ένα αρχείο Microsoft Project στη μνήμη, παρέχοντας πρόσβαση σε εργασίες, πόρους και προσαρμοσμένα πεδία. Η φόρτωση του αρχείου σας δίνει ένα διαχειρίσιμο μοντέλο αντικειμένων.

```java
Project project = new Project(dataDir + "project.mpp");
```

## Βήμα 3: προσθήκη προσαρμοσμένου πεδίου και δημιουργία τύπου προσαρμοσμένου πεδίου
Σε αυτό το βήμα **προσθέτουμε ένα προσαρμοσμένο πεδίο** “Double Costs” και **δημιουργούμε τύπο προσαρμοσμένου πεδίου** που πολλαπλασιάζει το `[Cost]` της εργασίας με 2, υλοποιώντας αποτελεσματικά έναν **double task cost formula**. Η μέθοδος `setFormula` ενσωματώνει τον υπολογισμό απευθείας στο αρχείο έργου.

```java
project.set(Prj.NEW_TASKS_ARE_MANUAL, new NullableBool(false));
ExtendedAttributeDefinition attr = ExtendedAttributeDefinition.createTaskDefinition(
        CustomFieldType.Text, ExtendedAttributeTask.Text1, "Custom");
attr.setAlias("Double Costs");
attr.setFormula("[Cost]*2");   // This formula doubles the task cost
project.getExtendedAttributes().add(attr);
```

## Βήμα 4: προσθήκη εργασίας και ορισμός κόστους
Δημιουργήστε μια νέα εργασία, στη συνέχεια ορίστε ένα βασικό κόστος `100`. Όταν το έργο αποθηκευτεί, το προσαρμοσμένο πεδίο θα εμφανίσει αυτόματα `200` λόγω του τύπου που ορίστηκε νωρίτερα.

```java
Task task = project.getRootTask().getChildren().add("Task");
task.set(Tsk.COST, BigDecimal.valueOf(100));
```

## Βήμα 5: αποθήκευση αρχείου έργου
Η μέθοδος `save` γράφει το ενημερωμένο έργο, συμπεριλαμβανομένου του νέου προσαρμοσμένου πεδίου και των υπολογισμένων τιμών του, στο `saved.mpp`. Αυτό διατηρεί τις αλλαγές **create custom field aspose** για οποιουδήποτε downstream καταναλωτές.

```java
project.save(dataDir + "saved.mpp", SaveFileFormat.Mpp);
```

## Κοινά προβλήματα και λύσεις
| Πρόβλημα | Αιτία | Διόρθωση |
|-------|--------|-----|
| **Ο τύπος δεν εφαρμόστηκε** | Το προσαρμοσμένο πεδίο δεν προστέθηκε στη συλλογή `ExtendedAttributes` του έργου. | Βεβαιωθείτε ότι εκτελείται `project.getExtendedAttributes().add(attr);` πριν από την αποθήκευση. |
| **Το αρχείο δεν βρέθηκε** | Λανθασμένη διαδρομή `dataDir`. | Επαληθεύστε ότι η συμβολοσειρά του καταλόγου λήγει με διαχωριστικό διαδρομής (`/` ή `\\`). |
| **Το κόστος εμφανίζεται ως 0** | Το κόστος της εργασίας δεν ορίστηκε πριν από την αποθήκευση. | Καλέστε `task.set(Tsk.COST, ...)` πριν από `project.save`. |

## Συχνές ερωτήσεις
**Q: Είναι το Aspose.Tasks συμβατό με όλες τις εκδόσεις του MS Project;**  
A: Ναι, το Aspose.Tasks υποστηρίζει ένα ευρύ φάσμα εκδόσεων του MS Project, από παλαιότερες μορφές .mpp έως τις πιο πρόσφατες εκδόσεις, καλύπτοντας πάνω από 30 παραλλαγές μορφών αρχείων.

**Q: Μπορώ να ενσωματώσω το Aspose.Tasks στο υπάρχον Java project μου;**  
A: Απολύτως. Το API έχει σχεδιαστεί για απρόσκοπτη ενσωμάτωση· απλώς προσθέστε το JAR του Aspose.Tasks στο classpath του project σας και ξεκινήστε να χρησιμοποιείτε την κλάση `Project`.

**Q: Υπάρχουν περιορισμοί στους τύπους των τύπων που μπορώ να δημιουργήσω;**  
A: Η βιβλιοθήκη υποστηρίζει τις περισσότερες εγγενείς συντακτικές δομές τύπων του MS Project, συμπεριλαμβανομένων των αριθμητικών, λογικών και ενσωματωμένων συναρτήσεων. Πολύπλοκες προσαρμοσμένες συναρτήσεις μπορεί να απαιτούν εναλλακτικές λύσεις, αλλά οι κοινές υπολογιστικές λειτουργίες όπως **double task cost formula** λειτουργούν αμέσως.

**Q: Υποστηρίζει το Aspose.Tasks ανάπτυξη σε πολλαπλές πλατφόρμες;**  
A: Ναι, η βιβλιοθήκη τρέχει σε οποιαδήποτε πλατφόρμα που υποστηρίζει Java, συμπεριλαμβανομένων των Windows, Linux και macOS, και μπορεί να διαχειριστεί έργα έως 2 GB χωρίς να φορτώνει ολόκληρο το αρχείο στη μνήμη.

**Q: Πώς μπορώ να λάβω τεχνική υποστήριξη για το Aspose.Tasks;**  
A: Επισκεφθείτε το [Aspose.Tasks community forum](https://forum.aspose.com/c/tasks/15) για βοήθεια από την κοινότητα, ή ανοίξτε ένα ticket υποστήριξης εάν έχετε εμπορική άδεια.
