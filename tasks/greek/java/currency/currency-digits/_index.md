# Πώς να λάβετε το νόμισμα του MS Project χρησιμοποιώντας το Aspose.Tasks

## Εισαγωγή
Αν αναρωτιέστε **πώς να λάβετε πληροφορίες για το νόμισμα του MS Project** από ένα αρχείο Microsoft Project, βρίσκεστε στο σωστό μέρος. Σε αυτό το ολοκληρωμένο tutorial θα ανακαλύψετε **πώς να εργάζεστε με τις τιμές του νομίσματος του MS Project** χρησιμοποιώντας τη βιβλιοθήκη Aspose.Tasks για Java. Είτε δημιουργείτε ένα εργαλείο αναφορών, ένα βοηθητικό πρόγραμμα μεταφοράς, είτε απλώς χρειάζεστε να διαβάσετε τις ρυθμίσεις νομίσματος από ένα **αρχείο java project**, αυτός ο οδηγός σας καθοδηγεί βήμα προς βήμα—από τη φόρτωση ενός αρχείου *.mpp* μέχρι την εξαγωγή των ψηφίων νομίσματος. Στο τέλος, θα είστε άνετοι με τη διαχείριση των δεδομένων νομίσματος του MS Project στις δικές σας εφαρμογές.

## Γρήγορες απαντήσεις
- **Ποια βιβλιοθήκη διαβάζει αρχεία MS Project;** Aspose.Tasks for Java.  
- **Πόσες γραμμές κώδικα χρειάζονται για να λάβετε τα ψηφία νομίσματος;** Μόνο τρεις σύντομες γραμμές μετά τη φόρτωση του έργου.  
- **Χρειάζομαι άδεια για ανάπτυξη;** Μια δωρεάν δοκιμή λειτουργεί για δοκιμές· απαιτείται εμπορική άδεια για παραγωγή.  
- **Ποια έκδοση της Java υποστηρίζεται;** Java 8 ή νεότερη (οποιοδήποτε JDK που εκτελεί το Aspose.Tasks).  
- **Μπορώ να ανακτήσω άλλες ιδιότητες του Project;** Ναι – το Aspose.Tasks εκθέτει ένα πλήρες σύνολο πεδίων του Project (π.χ., ημερομηνία έναρξης, τιμές κόστους κ.λπ.).

## Τι είναι το νόμισμα του MS Project;
Η ιδιότητα `ms project currency` ορίζει τον αριθμό των δεκαδικών ψηφίων που χρησιμοποιεί το Microsoft Project κατά την εμφάνιση χρηματικών τιμών. Αποθηκεύεται στο αρχείο Project ως το πεδίο **CURRENCY_DIGITS** και καθορίζει αν τα ποσά εμφανίζονται ως ακέραιοι, με ένα δεκαδικό, δύο δεκαδικά κ.λπ. Αυτή η ρύθμιση επηρεάζει άμεσα τις αναφορές προϋπολογισμού, τις συγκεντρώσεις κόστους και οποιοδήποτε UI που εμφανίζει οικονομικά στοιχεία, καθιστώντας την ουσιώδη για ακριβή ανταλλαγή δεδομένων.

## Γιατί να χρησιμοποιήσετε το Aspose.Tasks για τη διαχείριση του νομίσματος του MS Project;
Το Aspose.Tasks σας επιτρέπει να εξάγετε τα ψηφία νομίσματος χωρίς να εγκαταστήσετε το Microsoft Project, και το κάνει με απόδοση επιπέδου επιχειρήσεων. Η βιβλιοθήκη υποστηρίζει **30+ χρόνια εκδόσεων αρχείων Project**—από το Project 2000 μέχρι το Project 2024—καλύπτοντας περισσότερα από **150 διαφορετικά σχήματα αρχείων**. Η φόρτωση ενός έργου 500 σελίδων συνήθως διαρκεί κάτω από **2 δευτερόλεπτα** σε έναν τυπικό διακομιστή, και μπορείτε να ερωτήσετε μόνο τα πεδία που χρειάζεστε, διατηρώντας τη χρήση μνήμης κάτω από **50 MB** ακόμη και για τα μεγαλύτερα χρονοδιαγράμματα.

## Προαπαιτούμενα
Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε τα εξής:

1. **Περιβάλλον Ανάπτυξης Java** – εγκατεστημένο και ρυθμισμένο JDK 8 ή νεότερο.  
2. **Aspose.Tasks for Java** – κατεβάστε το τελευταίο JAR από την επίσημη ιστοσελίδα: [Aspose.Tasks for Java](https://releases.aspose.com/tasks/java/).  
3. **Βασικές γνώσεις Java** – πρέπει να μπορείτε να δημιουργήσετε ένα έργο Java, να προσθέσετε εξωτερικές βιβλιοθήκες και να εκτελέσετε μια `main` μέθοδο.  

## Εισαγωγή πακέτων
Πρώτα, εισάγετε τις κλάσεις που θα χρειαστούμε.  
Εισάγετε την κλάση `Project` και τα συναφή βοηθητικά εργαλεία από τη βιβλιοθήκη Aspose.Tasks.  
```java
import java.io.IOException;
import com.aspose.tasks.Prj;
import com.aspose.tasks.Project;
import com.aspose.tasks.SaveFileFormat;
```

## Βήμα 1: ορισμός καταλόγου δεδομένων
Καθορίστε το φάκελο που περιέχει το **java project file** (`*.mpp`).  
```java
String dataDir = "Your Data Directory";
```
Αντικαταστήστε το `"Your Data Directory"` με το απόλυτο ή σχετικό μονοπάτι όπου βρίσκεται το `project.mpp`.

## Βήμα 2: φόρτωση του αρχείου mpp  
Τώρα θα δούμε **πώς να φορτώσετε αρχεία mpp** χρησιμοποιώντας το Aspose.Tasks.  
Η κλάση `Project` αντιπροσωπεύει ένα αρχείο Microsoft Project και παρέχει πρόσβαση στις ιδιότητές του.  
```java
Project project = new Project(dataDir + "project.mpp");
```
Βεβαιωθείτε ότι το όνομα του αρχείου ταιριάζει ακριβώς· διαφορετικά, θα ριχτεί μια `IOException`.

## Βήμα 3: ανάκτηση ψηφίων νομίσματος  
Με το έργο φορτωμένο, η εξαγωγή των **ms project currency** ψηφίων είναι μια γραμμή κώδικα:  
Η μέθοδος `getCurrencyDigits()` επιστρέφει τον αριθμό των δεκαδικών ψηφίων που ορίζονται για χρηματικές τιμές.  
```java
System.out.println(project.get(Prj.CURRENCY_DIGITS));
```
Η κλήση επιστρέφει ένα `Integer` που αντιπροσωπεύει τον αριθμό των δεκαδικών ψηφίων (π.χ., `2` για σεντς). Η τιμή εκτυπώνεται στην κονσόλα, αλλά μπορείτε επίσης να την αποθηκεύσετε σε μεταβλητή για περαιτέρω επεξεργασία.

## Κοινά προβλήματα & συμβουλές
- **Αρχείο δεν βρέθηκε** – ελέγξτε ξανά τη διαδρομή `dataDir` και βεβαιωθείτε ότι το όνομα του αρχείου είναι σωστό, συμπεριλαμβανομένης της επέκτασης `.mpp`.  
- **Μη υποστηριζόμενη έκδοση αρχείου** – το Aspose.Tasks υποστηρίζει μορφές Project 2000‑2024· παλαιότερα ή κατεστραμμένα αρχεία μπορεί να χρειάζονται μετατροπή.  
- **Άδεια δεν έχει οριστεί** – κατά την ανάπτυξη λειτουργεί η δοκιμαστική έκδοση, αλλά για παραγωγή πρέπει να εφαρμόσετε έγκυρη άδεια ώστε να αποφύγετε τα υδατογράμματα αξιολόγησης.
