# Aspose.Tasks를 사용하여 Java에서 통화 기호 가져오기

## 소개
이 튜토리얼에서는 Aspose.Tasks for Java API를 사용하여 Microsoft Project (*.mpp*) 파일에서 **get currency symbol java**와 **extract currency code java**를 가져옵니다. Aspose.Tasks는 Java를 지원하는 모든 플랫폼에서 작동하므로 Microsoft Project를 로컬에 설치할 필요가 없습니다. 가이드가 끝날 때쯤에는 프로젝트 파일에서 ISO 통화 코드, 표시 기호, 소수점 자리수 및 기호 위치를 직접 읽을 수 있게 되어, 정확한 통화 메타데이터를 보고서, ERP 시스템 또는 맞춤형 대시보드에 제공할 수 있습니다.

## 빠른 답변
- **“get currency symbol java”는 무엇을 의미합니까?** Java 코드를 통해 MS Project 파일에서 통화 관련 메타데이터(코드, 기호, 자리수, 위치)를 검색하는 것을 의미합니다.  
- **이것을 시도하려면 라이선스가 필요합니까?** Aspose.Tasks의 무료 체험판을 사용할 수 있으며, 실제 사용을 위해서는 상업용 라이선스가 필요합니다.  
- **필요한 JDK 버전은 무엇입니까?** Java 8 이상.  
- **읽은 후에 통화 설정을 수정할 수 있습니까?** 예, Aspose.Tasks를 사용하면 통화 속성을 읽고 쓸 수 있습니다.  
- **이것이 모든 .mpp 버전과 호환됩니까?** API는 Microsoft Project 2003‑2021에서 만든 파일을 지원합니다.

## get currency symbol java란 무엇입니까?
Aspose.Tasks로 프로젝트를 로드하고 적절한 속성 키를 호출하면 원본 Project 파일에서 사용하는 통화 기호를 반환합니다. 이 작업을 통해 Microsoft Project에서 생성된 보고서에 표시되는 정확한 문자(예: `$`, `€`, `¥`)를 얻을 수 있습니다. 메서드는 통화 값에 사용되는 정확한 문자를 반환하므로, 생성된 모든 보고서가 원본 프로젝트의 서식 및 로케일 설정과 일치합니다.

## Aspose.Tasks를 사용하여 Java에서 통화 속성을 읽는 이유
Microsoft Project를 실행하지 않고도 통화 설정을 가져올 수 있어 시간과 서버 자원을 절약할 수 있습니다. Aspose.Tasks는 일반적인 200페이지 .mpp 파일을 30 ms 미만으로 처리하며, 전체 문서를 메모리에 로드하지 않고도 최대 500 MB 파일을 처리할 수 있습니다—대량 처리에 적합한 성능을 수치로 제시합니다.

## 사전 요구 사항
1. **Java Development Kit (JDK)** – Java 8 이상이 설치되어 `PATH`에 추가되어 있어야 합니다.  
2. **Aspose.Tasks for Java JAR** – [download the latest Aspose.Tasks for Java library](https://releases.aspose.com/tasks/java/)에서 최신 Aspose.Tasks for Java 라이브러리를 다운로드하고 프로젝트의 클래스패스에 추가합니다.  
3. (선택) **License file** – 프로덕션 환경에서 코드를 실행하려는 경우 유효한 `.lic` 파일이 필요합니다.

## 패키지 가져오기
프로젝트 조작에 필요한 Aspose.Tasks 네임스페이스를 가져오는 것으로 시작합니다:

```java
import com.aspose.tasks.*;
```

## 단계 1: 프로젝트 디렉터리 설정
분석하려는 `.mpp` 파일이 들어 있는 폴더를 정의합니다. 경로를 변수에 저장하면 코드를 재사용하고 테스트하기 쉬워집니다:

```java
String dataDir = "Your Data Directory";
```

*`"Your Data Directory"`를 `project.mpp` 파일이 위치한 폴더의 절대 경로나 상대 경로로 교체하십시오.*

## 단계 2: 프로젝트 리더 인스턴스 생성
`Project` 클래스는 메모리 내에서 Microsoft Project 파일을 나타내는 Aspose.Tasks의 핵심 객체입니다. 파일을 로드하면 통화 설정을 포함한 모든 프로젝트 수준 속성에 프로그래밍 방식으로 접근할 수 있습니다:

```java
Project project = new Project(dataDir + "project.mpp");
```

## 단계 3: 통화 속성 표시
`Prj` 열거형은 통화 설정과 같은 프로젝트 속성에 대한 키를 제공합니다. 각 키를 `project.get(...)`으로 조회하고 결과를 읽기 쉬운 타입으로 캐스팅할 수 있습니다:

```java
System.out.println("Currency Code : " + project.get(Prj.CURRENCY_CODE).toString());
System.out.println("<br>Currency Digits : " + project.get(Prj.CURRENCY_DIGITS).toString());
System.out.println("<br>Currency Symbol : " + project.get(Prj.CURRENCY_SYMBOL).toString());
System.out.println("Currency Symbol Position : " + project.get(Prj.CURRENCY_SYMBOL_POSITION).toString());
```

**보게 될 내용:**  
- **Currency Code** – `USD`, `EUR`, `JPY`와 같은 ISO‑4217 코드.  
- **Currency Digits** – 대부분의 통화는 보통 `2`이며, 일본 엔은 `0`입니다.  
- **Currency Symbol** – 보고서에 표시되는 문자(`$`, `€`, `¥`).  
- **Currency Symbol Position** – 금액 앞에 표시하려면 `0`, 뒤에 표시하려면 `1`.

## currency symbol java를 가져오는 방법은?
프로젝트를 로드한 후 `project.get(Prj.CURRENCY_SYMBOL)`을 호출합니다; 이 메서드는 파일에서 사용된 정확한 기호 문자열을 반환합니다. 이 한 줄만으로도 기호를 모든 하위 금융 UI 또는 보고 엔진에 전달할 수 있습니다. 이후 이 문자열을 변수에 저장하거나 로그에 기록하거나, 표시 또는 계산에 통화 기호가 필요한 다른 구성 요소에 전달할 수 있습니다.

## 단계 4: 처리 완료
추출이 성공적으로 완료되었음을 알립니다. 이 간단한 메시지는 코드가 대규모 배치 작업의 일부로 실행될 때 유용합니다:

```java
System.out.println("Process completed Successfully");
```

## 일반적인 문제 및 해결책
| Issue | Why it happens | Fix |
|-------|----------------|-----|
| **FileNotFoundException** | `dataDir` 경로가 올바르지 않거나 파일 이름이 잘못 입력되었습니다. | 디렉터리 문자열을 확인하고 지정된 위치에 `.mpp` 파일이 존재하는지 확인하십시오. |
| **NullPointerException on `project.get(...)`** | 프로젝트 파일에 통화 정보가 포함되어 있지 않거나(드물게) 속성 키가 잘못되었습니다. | `project.contains(Prj.CURRENCY_CODE)`를 사용하여 읽기 전에 존재 여부를 확인하십시오. |
| **LicenseException** | 프로덕션 환경에서 유효한 Aspose.Tasks 라이선스 없이 실행하고 있습니다. | `License license = new License(); license.setLicense("Aspose.Tasks.lic");` 코드를 사용해 `Project` 객체를 생성하기 전에 라이선스 파일을 로드합니다. |
| **OutOfMemoryError on large files** | 스트리밍 없이 매우 큰 .mpp 파일을 로드하려고 시도했습니다. | Aspose.Tasks는 저메모리 모드로 파일을 처리하므로 버전 24.12 이상을 사용하고 있는지 확인하십시오. |
