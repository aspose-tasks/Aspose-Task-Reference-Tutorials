# 如何使用 Aspose.Tasks 取得貨幣符號（java）

## 介紹
在本教學中，您將 **取得貨幣符號 java** 並同時 **擷取貨幣代碼 java**，從 Microsoft Project（*.mpp*）檔案中使用 Aspose.Tasks for Java API。Aspose.Tasks 可在任何支援 Java 的平台上執行，無需本機安裝 Microsoft Project。完成本指南後，您將能直接從專案檔讀取 ISO 貨幣代碼、顯示符號、小數位數以及符號位置，讓您能將正確的貨幣中繼資料匯入報表、ERP 系統或自訂儀表板。

## 快速解答
- **「get currency symbol java」是什麼意思？** 代表透過 Java 程式碼從 MS Project 檔案中取得與貨幣相關的中繼資料（代碼、符號、位數、位置）。  
- **我需要授權才能嘗試嗎？** 提供 Aspose.Tasks 的免費試用版；商業使用需購買正式授權。  
- **需要哪個版本的 JDK？** Java 8 或更高版本。  
- **讀取後可以修改貨幣設定嗎？** 可以，Aspose.Tasks 同時支援讀寫貨幣屬性。  
- **是否相容所有 .mpp 版本？** API 支援 Microsoft Project 2003‑2021 所產生的檔案。

## 什麼是 get currency symbol java？
使用 Aspose.Tasks 載入專案並呼叫相應的屬性鍵，即可取得原始 Project 檔案使用的貨幣符號。此操作會回傳實際的字元（例如 `$`、`€`、`¥`），與 Microsoft Project 產生的報表中顯示的完全相同。此方法確保任何產生的報表都符合原始專案的格式與語系設定。

## 為什麼要使用 Aspose.Tasks 讀取貨幣屬性 (java)？
您可以在不啟動 Microsoft Project 的情況下取得貨幣設定，節省時間與伺服器資源。Aspose.Tasks 能在 30 ms 內處理一個 200 頁的 .mpp 檔，且可處理高達 500 MB 的檔案而不需將整個文件載入記憶體——這是一項具體的效能宣稱，使大量批次處理成為可能。

## 前置條件
在開始之前，請確保您已具備：

1. **Java Development Kit (JDK)** – 已安裝 Java 8 或更新版本，並加入 `PATH`。  
2. **Aspose.Tasks for Java JAR** – 從 [download the latest Aspose.Tasks for Java library](https://releases.aspose.com/tasks/java/) 下載最新的 Aspose.Tasks for Java 程式庫，並加入專案的 classpath。  
3. (Optional) **License file** – 若在正式環境執行程式，需提供有效的 `.lic` 授權檔。

## 匯入套件
先匯入 Aspose.Tasks 所需的命名空間，以便操作專案：

```java
import com.aspose.tasks.*;
```

## 第一步：設定專案目錄
定義包含欲分析的 `.mpp` 檔案的資料夾。將路徑存於變數中，可提升程式的可重用性與可測試性：

```java
String dataDir = "Your Data Directory";
```

*將 `"Your Data Directory"` 替換為 `project.mpp` 所在資料夾的絕對或相對路徑。*

## 第二步：建立專案讀取器實例
`Project` 類別是 Aspose.Tasks 的核心物件，代表記憶體中的 Microsoft Project 檔案。載入檔案後，即可程式化存取每個專案層級的屬性，包括貨幣設定：

```java
Project project = new Project(dataDir + "project.mpp");
```

## 第三步：顯示貨幣屬性
`Prj` 列舉提供了貨幣相關的屬性鍵。您可以使用 `project.get(...)` 取得每個鍵的值，並轉型為可讀的型別：

```java
System.out.println("Currency Code : " + project.get(Prj.CURRENCY_CODE).toString());
System.out.println("<br>Currency Digits : " + project.get(Prj.CURRENCY_DIGITS).toString());
System.out.println("<br>Currency Symbol : " + project.get(Prj.CURRENCY_SYMBOL).toString());
System.out.println("Currency Symbol Position : " + project.get(Prj.CURRENCY_SYMBOL_POSITION).toString());
```

**您將看到的資訊：**  
- **Currency Code** – ISO‑4217 代碼，例如 `USD`、`EUR`、`JPY`。  
- **Currency Digits** – 大多數貨幣為 `2` 位，小數點後零位的例子如日圓 `0`。  
- **Currency Symbol** – 報表中顯示的字元（`$`、`€`、`¥`）。  
- **Currency Symbol Position** – `0` 代表 **前置** 金額，`1` 代表 **後置**。

## 如何取得貨幣符號 java？
載入專案後，呼叫 `project.get(Prj.CURRENCY_SYMBOL)`；此方法會回傳檔案使用的確切符號字串。只需一行程式碼，即可將符號傳遞至任何下游的金融 UI 或報表引擎。您可以將此字串儲存於變數、寫入日誌，或傳給其他需要顯示貨幣符號的元件。

## 第四步：處理完成
在批次作業中顯示提取成功的訊息，有助於監控：

```java
System.out.println("Process completed Successfully");
```

## 常見問題與解決方案
| 問題 | 為何會發生 | 解決方式 |
|-------|----------------|-----|
| **FileNotFoundException** | `dataDir` 路徑不正確或檔名拼寫錯誤。 | 核對目錄字串，確保 `.mpp` 檔案存在於指定位置。 |
| **NullPointerException on `project.get(...)`** | 專案檔未包含貨幣資訊（可能性低）或屬性鍵錯誤。 | 在讀取前使用 `project.contains(Prj.CURRENCY_CODE)` 檢查是否存在。 |
| **LicenseException** | 在正式環境未使用有效的 Aspose.Tasks 授權。 | `License license = new License(); license.setLicense("Aspose.Tasks.lic");` 於建立 `Project` 物件前載入授權檔。 |
| **OutOfMemoryError on large files** | 嘗試載入過大的 .mpp 檔案而未使用串流。 | Aspose.Tasks 具備低記憶體模式；請確保使用 24.12 版或更新版本。 |
