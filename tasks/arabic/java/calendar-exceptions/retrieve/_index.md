## ما هي فئة Project؟
`Project` تمثل ملف MS Project محملاً في الذاكرة. إنها الكائن الأساسي في Aspose.Tasks الذي يمنحك الوصول إلى التقويمات، والمهام، والموارد، وغيرها من بيانات المشروع عبر API نظيف وموجه كائنات. باستخدام فئة `Project` يمكنك الاستعلام وتعديل كل عنصر في المشروع دون الحاجة إلى تثبيت Microsoft Project، مما يجعلها مثالية للمعالجة على الخادم وإعداد التقارير الآلية.

## الخطوة 1: إعداد دليل البيانات الخاص بك
حدد مجلدًا يحتوي على ملف Project الذي تريد تحليله. استخدام مسار مطلق أو مسار نسبي إلى مجلد الموارد في مشروعك يمنع حدوث `FileNotFoundException`.

```java
String dataDir = "C:/Projects/Data/";
```

> **نصيحة احترافية:** احفظ ملفات Project في مجلد موارد مخصص وارجع إليها باستخدام `Paths.get(...)` للحصول على مسارات مستقلة عن المنصة.

## الخطوة 2: تحميل ملف MS Project
فئة `Project` تمثل ملف MS Project وتوفر الوصول إلى تقويماته، ومهامه، وموارده، وغيرها من بيانات المشروع. قم بتحميل ملف Project إلى كائن `Project`. هذا الكائن يمثل ملف MS Project بالكامل في الذاكرة ويوفر الوصول إلى التقويمات، والمهام، والموارد، وأكثر.

```java
Project project = new Project(dataDir + "project.mpp");
```

## كيف تسترجع استثناءات التقويم من مشروع محمّل؟
قم بالتكرار عبر كل تقويم في المشروع ثم عبر كل استثناء تقويم داخل ذلك التقويم. اطبع تاريخ البداية والنهاية لكل استثناء. يضمن هذا الحلقة ذات المستويين التقاط كل استثناء، حتى إذا كان المشروع يحتوي على تقاويم متعددة (قياسي، موارد، أو مخصص). من خلال فحص كل `CalendarException` يمكنك إنشاء تقارير مخصصة، تعديل الجداول الزمنية، أو تصدير البيانات إلى أنظمة أخرى.

```java
for (Calendar cal : project.getCalendars()) {
    for (CalendarException calExc : cal.getExceptions()) {
        System.out.println("Exception from " + calExc.getFromDate() + " to " + calExc.getToDate());
    }
}
```

## المشكلات الشائعة والحلول
| المشكلة | السبب | الحل |
|-------|--------|-----|
| **لا يتم طباعة أي إخراج** | ملف المشروع لا يحتوي على أي استثناءات تقويم. | تحقق من أن التقويم في MS Project يحتوي على استثناءات معرفة (مثل العطلات). |
| **`NullPointerException`** | مسار `dataDir` غير صحيح أو الملف غير موجود. | تحقق مرة أخرى من مسار الدليل وتأكد من وجود `project.mpp`. |
| **عدم تطابق المنطقة الزمنية** | التواريخ معروضة بتوقيت UTC. | استخدم `calExc.getFromDate().toLocalDateTime()` لتحويلها إلى الوقت المحلي إذا لزم الأمر. |
