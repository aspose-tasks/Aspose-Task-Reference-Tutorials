# كيفية مراقبة العمل الإضافي وتكاليف العمل باستخدام Aspose.Tasks

في هذا البرنامج التعليمي ستتعلم **كيفية مراقبة العمل الإضافي** وتكاليف العمل باستخدام Aspose.Tasks for Java. سنستعرض تحميل ملف MPP، والتكرار عبر تعيينات الموارد، واستخراج بيانات العمل الإضافي، والعمل المتبقي، والتكلفة حتى تتمكن من الحفاظ على المشاريع ضمن الجدول الزمني والميزانية.

## إجابات سريعة
- **ما الذي يمكنني مراقبته؟** تكلفة العمل الإضافي، عمل العمل الإضافي، التكلفة المتبقية، العمل المتبقي، وتكلفة العمل الإضافي المتبقية.  
- **ما المكتبة المطلوبة؟** Aspose.Tasks for Java.  
- **هل أحتاج إلى ترخيص للتطوير؟** النسخة التجريبية المجانية تكفي للاختبار؛ يلزم وجود ترخيص للإنتاج.  
- **هل يمكنني تحميل ملفات .mpp موجودة؟** نعم، ما عليك سوى توفير مسار الملف.  
- **هل Java 6 كافية؟** تدعم API Java SE 6 وما بعدها.

## كيفية مراقبة العمل الإضافي وتكاليف العمل؟
قم بتحميل المشروع، وتكرار كل `ResourceAssignment`، وقراءة الخصائص المتعلقة بالعمل الإضافي—يمكن إنجاز هذه العملية بأقل من عشر أسطر من كود Java. تُعيد API القيم بعملات المشروع، ويمكنك دمجها مع مقاييس أخرى لإنشاء لوحة متابعة تكلفة كاملة.

## ما هو مراقبة تكلفة المشروع؟
مراقبة تكلفة المشروع هي العملية المستمرة لتتبع النفقات المخططة، الفعلية، والمتوقعة عبر جميع الموارد في المشروع. توفر لك رؤية فورية إلى أين تُنفق الأموال، تساعدك على اكتشاف تجاوزات العمل الإضافي مبكرًا، وتمكنك من توقع دقيق للعمل المتبقي.

## لماذا نراقب العمل الإضافي والعمل المتبقي؟
العمل الإضافي هو العامل الرئيسي لتجاوز الميزانية غير المتوقعة، حيث يمثل ما يصل إلى **35 %** من تباين التكلفة في العديد من المشاريع الكبيرة. من خلال قياس العمل الإضافي والعمل المتبقي يمكنك:
- **التحكم في الميزانيات:** اكتشاف ارتفاعات التكلفة قبل أن تصبح حرجة.  
- **تحسين التنبؤ:** تعديل الجداول بناءً على تقديرات العمل المتبقي، مما يقلل انزلاق الجدول الزمني حتى **20 %**.  
- **زيادة الشفافية:** تزويد أصحاب المصلحة بأرقام ملموسة بدلاً من تقديرات غامضة.

## المتطلبات المسبقة

2. **مكتبة Aspose.Tasks for Java:** قم بتنزيل وتثبيت المكتبة من [هنا](https://releases.aspose.com/tasks/java/).  
3. **بيئة تطوير متكاملة (IDE):** أي IDE للـ Java مثل Eclipse أو IntelliJ IDEA أو NetBeans.

## استيراد الحزم

توفر الاستيرادات التالية الوصول إلى الفئات الأساسية لإدارة المشروع التي ستحتاجها. Asn هي فئة مساعدة للعمل مع بيانات التعيين المحددة.

```java
import com.aspose.tasks.Asn;
import com.aspose.tasks.Project;
import com.aspose.tasks.ResourceAssignment;
```

## الخطوة 1: إعداد دليل البيانات

حدد المجلد الذي يحتوي على ملف MPP الخاص بك. استخدام مسار مطلق أو نسبي يعمل بنفس الطريقة.

```java
String dataDir = "Your Data Directory";
```  
استبدل `"Your Data Directory"` بالمسار إلى ملف مشروعك.

## الخطوة 2: تحميل المشروع

`Project` هو الكائن الأعلى مستوى في Aspose.Tasks الذي يمثل ملف Microsoft Project كامل في الذاكرة. إن إنشاء مثيل له يحمل الملف ويجهز جميع المجموعات الداخلية للاستخدام.

```java
Project project = new Project(dataDir + "ResourceAssignmentOvertimes.mpp");
```  
استبدل `"ResourceAssignmentOvertimes.mpp"` باسم ملف MPP الخاص بك. تُظهر هذه الخطوة استخدام **تحميل ملف mpp**.

## الخطوة 3: التكرار عبر تعيينات الموارد

`ResourceAssignment` يمثل الرابط بين المورد والمهمة، ويكشف عن تفاصيل التكلفة والعمل والعمل الإضافي. يسمح لك التكرار عبر المجموعة بفحص كل تعيين على حدة.

```java
for (ResourceAssignment ra : project.getResourceAssignments()) {
```

## الخطوة 4: طباعة تكاليف العمل الإضافي والعمل

استخرج المقاييس المتعلقة بالعمل الإضافي مباشرةً من كل `ResourceAssignment`. تُعبّر هذه القيم بعملات المشروع ووحدات الوقت.

```java
    System.out.println(ra.get(Asn.OVERTIME_COST));
    System.out.println(ra.get(Asn.OVERTIME_WORK).toString());
```

## الخطوة 5: طباعة التكاليف والعمل المتبقي

توفر API خصائص `RemainingCost` و `RemainingWork`، التي تعكس الجهد والنفقات المتوقعة المتبقية لإكمال كل تعيين.

```java
    System.out.println(ra.get(Asn.REMAINING_COST));
    System.out.println(ra.get(Asn.REMAINING_WORK).toString());
```

## الخطوة 6: طباعة تكاليف العمل الإضافي المتبقية والعمل

`RemainingOvertimeCost` و `RemainingOvertimeWork` يمنحانك صورة واضحة عن الميزانية الإضافية والجهد المتبقي المتوقع بسبب العمل الإضافي.

```java
    System.out.println(ra.get(Asn.REMAINING_OVERTIME_COST));
    System.out.println(ra.get(Asn.REMAINING_OVERTIME_WORK).toString());
}
```

## المشكلات الشائعة والحلول
- **الملف غير موجود:** تحقق مرة أخرى من مسار `dataDir` وتأكد من صحة اسم ملف MPP.  
- **قيم فارغة:** قد تفتقر بعض التعيينات إلى بيانات العمل الإضافي؛ احرص على معالجة `null` عند الطباعة.  
- **عدم توافق الإصدارات:** استخدم نسخة المكتبة التي تتطابق مع تنسيق ملف MPP (مثل إصدارات MS Project الأحدث).
