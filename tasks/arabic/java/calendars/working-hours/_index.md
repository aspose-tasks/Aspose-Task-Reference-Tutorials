# كيفية إضافة تقويم العطلات وتحديد أيام العمل

إدارة تقاويم المشاريع هي جزء أساسي من تخطيط المشروع الناجح. في هذا البرنامج التعليمي ستقوم **بإضافة تقويم العطلات**، **تحديد أيام العمل** لأي مهمة، و**استخراج ساعات العمل** من تقويم MS Project باستخدام Aspose.Tasks for Java. في نهاية الدليل ستكون قادرًا على **حساب مدة المهمة**، تخصيص ساعات العمل، وتحميل **ملف MPP** بشكل موثوق لاسترجاع البيانات التي تحتاجها — كل ذلك دون تثبيت Microsoft Project.

## إجابات سريعة
- **ماذا يعني “تحديد أيام العمل”؟** يعني ذلك تحديد أي تواريخ التقويم تُعتبر أيام عمل لمهمة معينة.  
- **أي مكتبة يجب أن أستخدمها؟** Aspose.Tasks for Java توفر API متكامل للعمل مع ملفات MS Project.  
- **كم يستغرق التنفيذ؟** عادةً 10–15 دقيقة لاستخراج أساسي.  
- **هل أحتاج إلى ترخيص؟** يتوفر إصدار تجريبي مجاني؛ يلزم ترخيص تجاري للاستخدام في الإنتاج.  
- **هل يمكنني تخصيص ساعات العمل؟** نعم – يمكنك تعديل التقاويم، إضافة عطلات، وتحديد فترات عمل مخصصة.  

## ما هو “تحديد أيام العمل”؟
**تحديد أيام العمل** يعني استعلام تقويم المشروع لمعرفة أي تواريخ تم وضع علامة عليها كأيام عمل مقابل أيام غير عمل (عطلات نهاية الأسبوع، العطلات، أو استثناءات مخصصة). هذه المعلومات أساسية لحساب **مدة المهمة** بدقة لأن أيام العمل فقط هي التي تُساهم في الوقت المنقضي للمهمة.

## لماذا تستخدم Aspose.Tasks لاسترجاع ساعات العمل؟
Aspose.Tasks يتيح لك قراءة ملفات MS Project دون الحاجة إلى تثبيت Microsoft Project، مما يتيح الأتمتة على أي منصة. كما يوفر معالجة عالية الأداء، دعمًا واسعًا للتنسيقات، ووثائق مفصلة.  
- **دعم كامل للتقويم** – تقاويم الافتراضية، والموارد، والمهام كلها متاحة.  
- **أداء عالي** – يمكنه معالجة مشاريع تحتوي على **أكثر من 10,000 مهمة في أقل من ثانيتين** على معالج قياسي 2.5 GHz.  
- **تغطية شاملة للتنسيقات** – يدعم **أكثر من 50 تنسيقًا للإدخال والإخراج**، بما في ذلك MPP، MPX، XML، وPrimavera.  
- **وثائق شاملة** – عينات الكود، مرجع API، ومنتديات المجتمع كلها متاحة.  

## المتطلبات المسبقة
قبل البدء، تأكد من أن لديك:
1. **Java Development Kit (JDK)** – الإصدار 8 أو أعلى.  
2. **Aspose.Tasks for Java** – قم بتحميل أحدث JAR من [Aspose.Tasks for Java releases](https://releases.aspose.com/tasks/java/).  
3. معرفة أساسية ببرمجة Java.  

## استيراد الحزم
الفئة `Project` هي الكائن الأعلى مستوى في Aspose.Tasks الذي يمثل ملف MS Project واحد في الذاكرة. استورد النطاق المطلوب قبل البدء:

استيراد الحزم

```java
import com.aspose.tasks.*;
```

## كيفية تحميل ملف MPP باستخدام Aspose.Tasks؟
الفئة `Project` تقوم بتحميل ملف MS Project وتوفر الوصول إلى بياناته. حمّل ملف المشروع بسطر واحد من الكود؛ لا حاجة لواجهة مستخدم أو COM interop. هذه الخطوة البسيطة تمنحك وصولًا كاملًا إلى التقاويم، والمهام، والموارد.

تحميل ملف MPP

```java
String dataDir = "Your Data Directory";
Project project = new Project(dataDir + "project.mpp");
```

## استرجاع معلومات المهمة والتقويم
`Task` تمثل مهمة في المشروع، و`Calendar` يحدد قواعد وقت العمل الخاصة بها. اختر المهمة التي تريد تحليلها واحصل على التقويم المرتبط بها. كائن `Task` يوفر طريقتي `getStart()` و `getFinish()`، بينما كائن `Calendar` يكشف عن تعريفات وقت العمل.

استرجاع المهمة والتقويم

```java
Task task = project.getRootTask().getChildren().getById(1);
Calendar taskCalendar = task.get(Tsk.CALENDAR);
```

## تعريف تواريخ البداية والنهاية
كائنات `Date` تحدد نافذة الوقت لتحليل التقويم. اضبط نافذة الوقت التي تريد **تحديد أيام العمل** لها. استخدام تواريخ البداية والنهاية للمهمة يضمن تقييم الفترة ذات الصلة فقط.

تحديد التواريخ

```java
java.util.Calendar calStartDate = java.util.Calendar.getInstance();
calStartDate.setTime(task.get(Tsk.START));
java.util.Calendar calEndDate = java.util.Calendar.getInstance();
calEndDate.setTime(task.get(Tsk.FINISH));
```

## التكرار عبر التواريخ
يمكن حلقة `for` التكرار عبر كل يوم في نطاق التاريخ. تكرار عبر كل تاريخ في مدة المهمة. هذه الحلقة ستتيح لك **تخصيص ساعات العمل** لاحقًا إذا لزم الأمر وتعد أساسًا لحساب إجمالي وقت العمل.

التكرار عبر التواريخ

```java
java.util.Calendar tempDate = calStartDate;
```

## حساب المدة
`Duration` يجمع إجمالي وقت العمل المحسوب من التكرار. خلال التكرار تتحقق مما إذا كان كل يوم يوم عمل، تجمع ساعات العمل، وأخيرًا تحسب مدة المهمة بالدقائق، الساعات، والأيام. هذا يوضح كيفية **حساب أيام العمل** و**حساب مدة المهمة** برمجيًا.

حساب المدة

```java
double durationInMins = 0;
double durationInHours = 0;
double durationInDays = 0;
long OneSec = 10000000;
long OneMin = 60 * OneSec;
long OneHour = 60 * OneMin;
long timeSpan;
while (tempDate.before(calEndDate)) {
    if (taskCalendar.isDayWorking(tempDate.getTime())) {
        timeSpan = (long) taskCalendar.getWorkingHours(tempDate.getTime());
        durationInMins += (double) timeSpan / OneMin;
        durationInHours += (double) timeSpan / OneHour;
        if ((timeSpan / OneHour) > 0) {
            durationInDays += ((double) timeSpan / OneHour / 8.0);
        }
    }
    tempDate.add(java.util.Calendar.DATE, 1);
}
System.out.println("Duration in Minutes = " + durationInMins);
System.out.println("Duration in Hours = " + durationInHours);
System.out.println("Duration in Days = " + durationInDays);
System.out.println();
```

## كيفية تخصيص ساعات العمل والعطلات
يمكنك تعديل فترات وقت العمل في التقويم وإضافة استثناءات مثل العطلات. استخدم `taskCalendar.addWorkingTime()` لتحديد فترات عمل جديدة و `taskCalendar.addException()` لإدراج عطلة. هذا مفيد عندما لا يتطابق جدول 9‑5 الافتراضي مع سياسات مؤسستك.

## المشكلات الشائعة والحلول
| المشكلة | الحل |
|-------|----------|
| **المهمة تُعيد `null` للتقويم** | تأكد من أن المهمة لديها تقويم مُعين فعليًا؛ وإلا فإنها ستورث التقويم الافتراضي للمشروع. |
| **مدة غير صحيحة بسبب العطلات** | تحقق من أن العطلات مُعرفة في تقويم المهمة أو في التقويم الأساسي للمشروع. |
| **اختلاف المنطقة الزمنية** | استخدم `java.util.TimeZone` لمطابقة المنطقة الزمنية للتقويم مع نظامك إذا لزم الأمر. |
