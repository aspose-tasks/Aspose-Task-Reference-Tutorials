# استخراج رمز العملة mpp باستخدام Aspose.Tasks للـ Java

## مقدمة
في هذا الدرس ستتعلم كيفية العمل مع **java project properties** — وبشكل خاص كيفية **extract currency symbol mpp** من ملف Microsoft Project (MPP) وكيفية **change currency symbol java** أو **retrieve currency symbol java** باستخدام مكتبة Aspose.Tasks. سواءً كنت تبني أداة تقارير مالية، أو تدمج بيانات Project في نظام ERP، أو تحتاج ببساطة إلى عرض رمز العملة الصحيح في واجهة المستخدم الخاصة بك، فإن إتقان هذه المهمة الصغيرة ولكن الأساسية سيجعل تطبيقات Java أكثر قوة وسهولة في الاستخدام.

## إجابات سريعة
- **What does “extract currency symbol mpp” mean?** يعني قراءة رمز العملة المخزن في ملف MPP (Microsoft Project).  
- **Which library handles this?** توفر Aspose.Tasks for Java واجهة برمجة تطبيقات بسيطة لهذه المهمة.  
- **Do I need a license?** النسخة التجريبية المجانية تكفي للتطوير؛ يتطلب الإنتاج رخصة تجارية.  
- **How long does it take?** باستخدام الشيفرة أدناه، يمكنك الحصول على الرمز في أقل من دقيقة.  
- **Can I also change the symbol?** نعم – يمكنك تعيين قيمة جديدة باستخدام الخاصية نفسها `Prj.CURRENCY_SYMBOL`.

## ما هو “extract currency symbol mpp”؟
استخراج رمز العملة من ملف MPP يعني قراءة السلسلة ذات الحرف الواحد التي يخزنها Microsoft Project في رأس الملف لتمثيل الوحدة النقدية للمشروع. تسمح لك هذه العملية بعرض الرمز الصحيح (مثل $, €, £) في تطبيقاتك دون الحاجة إلى ترميز ثابت.

## لماذا تحديث رمز العملة في خصائص مشروع Java؟
تحديث رمز العملة يتيح لك تعريب التقارير والفواتير ولوحات التحكم في الوقت الفعلي. يمكن للمؤسسات التي تدير مشاريع عبر عدة مناطق تغيير الرمز بخطوة واحدة، مما يجنب الحاجة إلى تكرار ملف المشروع بالكامل. يمكن لـ Aspose.Tasks تعديل الخاصية في الذاكرة وحفظ الملف مرة أخرى، مع دعم المشاريع التي تحتوي على ما يصل إلى 2,000 مهمة دون تأثير ملحوظ على الأداء.

## المتطلبات المسبقة
1. **Java Development Kit (JDK)** – الإصدار 8 أو أعلى.  
2. **Aspose.Tasks for Java** – قم بتنزيل أحدث ملف JAR من [صفحة تنزيل Aspose.Tasks](https://releases.aspose.com/tasks/java/).  
3. ملف **project.mpp** صالح موجود في مجلد يمكنك الإشارة إليه من الشيفرة.

## استيراد الحزم
أولاً، استورد الفئات التي سنحتاجها للعمل مع ملفات Project.

```java
import com.aspose.tasks.Prj;
import com.aspose.tasks.Project;
```

## الخطوة 1: تعريف دليل البيانات
أخبر التطبيق بمكان وجود ملف *.mpp* الخاص بك.

```java
String dataDir = "Your Data Directory";
```

> **نصيحة احترافية:** استخدم `System.getProperty("user.dir")` لإنشاء مسار مطلق يعمل على أي جهاز.

## الخطوة 2: تحميل ملف MS Project
`Project` هو الكائن الأعلى مستوى في Aspose.Tasks والذي يمثل ملف Microsoft Project واحد في الذاكرة. إنشاء هذا الكائن يحمل بنية الملف دون الحاجة إلى تثبيت Microsoft Project.

```java
Project project = new Project(dataDir + "project.mpp");
```

## الخطوة 3: استرجاع (وتغيير اختياري) رمز العملة
`Prj.CURRENCY_SYMBOL` هو مفتاح الخاصية الذي يخزن رمز العملة. قراءته تُعيد الرمز الحالي؛ وتعيين سلسلة جديدة يُحدّث تعريف العملة في المشروع.

```java
// Retrieve the current currency symbol
System.out.println(project.get(Prj.CURRENCY_SYMBOL));

// Example of changing it (uncomment to use)
// project.set(Prj.CURRENCY_SYMBOL, "€");
// System.out.println("New symbol: " + project.get(Prj.CURRENCY_SYMBOL));
```

ستطبع الدالة `System.out.println` الرمز (مثلاً `$`) إلى وحدة التحكم، لتأكيد نجاح عملية الاستخراج.

## المشكلات الشائعة وكيفية إصلاحها
| العَرَض | السبب المحتمل | الحل |
|---------|--------------|----------|
| `NullPointerException` on `project.get(...)` | مسار ملف غير صحيح أو الملف غير موجود | تحقق من `dataDir` واسم الملف؛ استخدم `new File(dataDir).exists()` للتصحيح |
| Unexpected symbol (e.g., `?`) | تم إنشاء المشروع بإعدادات إقليمية غير قياسية | تأكد من أن ملف MPP المصدر يحدد رمز عملة فعليًا؛ يمكنك تعيين واحد برمجيًا كما هو موضح أعلاه |
| License error | استخدام النسخة التجريبية دون ملف ترخيص صالح | حمّل الترخيص الخاص بك باستخدام `License license = new License(); license.setLicense("Aspose.Tasks.Java.lic");` قبل إنشاء كائن `Project` |
