# كيفية الحصول على رمز العملة java باستخدام Aspose.Tasks

## مقدمة
في هذا الدرس ستحصل على **رمز العملة java** وكذلك **استخراج رمز العملة java** من ملفات Microsoft Project (*.mpp*) باستخدام Aspose.Tasks for Java API. يعمل Aspose.Tasks على أي منصة تدعم Java، لذا لا تحتاج إلى تثبيت محلي لـ Microsoft Project. في نهاية الدليل ستتمكن من قراءة رمز العملة ISO، ورمز العرض، وعدد الأرقام العشرية، وموقع الرمز مباشرةً من ملف المشروع، مما يتيح لك إدخال بيانات مالية دقيقة في التقارير، وأنظمة ERP، أو لوحات التحكم المخصصة.

## إجابات سريعة
- **ماذا يعني “get currency symbol java”؟** يعني استرجاع البيانات المتعلقة بالعملة (الرمز، الرمز النصي، عدد الأرقام، الموقع) من ملف MS Project عبر كود Java.  
- **هل أحتاج إلى ترخيص لتجربة ذلك؟** يتوفر نسخة تجريبية مجانية من Aspose.Tasks؛ يلزم الحصول على ترخيص تجاري للاستخدام في الإنتاج.  
- **ما نسخة JDK المطلوبة؟** Java 8 أو أعلى.  
- **هل يمكنني تعديل إعدادات العملة بعد قراءتها؟** نعم، يتيح لك Aspose.Tasks قراءة وكتابة خصائص العملة.  
- **هل هذا متوافق مع جميع إصدارات .mpp؟** يدعم الـ API الملفات التي تم إنشاؤها بـ Microsoft Project 2003‑2021.

## ما هو get currency symbol java؟
تحميل مشروع باستخدام Aspose.Tasks واستدعاء مفاتيح الخصائص المناسبة يعيد رمز العملة الذي يستخدمه ملف Project الأصلي. هذه العملية تعطيك الحرف الدقيق (مثل `$`، `€`، `¥`) الذي يظهر في التقارير التي يولدها Microsoft Project. تُعيد الطريقة الحرف المستخدم للقيم المالية، مما يضمن أن أي تقارير مُولدة تتطابق مع تنسيق المشروع الأصلي وإعدادات اللغة.

## لماذا قراءة خصائص العملة java باستخدام Aspose.Tasks؟
يمكنك استرجاع إعدادات العملة دون تشغيل Microsoft Project، مما يوفر الوقت وموارد الخادم. يعالج Aspose.Tasks ملف .mpp متوسط الحجم (200 صفحة) في أقل من 30 ms ويمكنه التعامل مع ملفات تصل إلى 500 MB دون تحميل المستند بالكامل في الذاكرة — وهو ادعاء أداء يُمكّن المعالجة الضخمة.

## المتطلبات المسبقة
قبل البدء، تأكد من وجود ما يلي:

1. **Java Development Kit (JDK)** – Java 8 أو أحدث مثبت ومضاف إلى `PATH`.  
2. **Aspose.Tasks for Java JAR** – قم بتحميل أحدث مكتبة Aspose.Tasks for Java من [download the latest Aspose.Tasks for Java library](https://releases.aspose.com/tasks/java/) وأضفها إلى مسار الـ classpath الخاص بمشروعك.  
3. (اختياري) **License file** – ملف `.lic` صالح إذا كنت تخطط لتشغيل الكود في بيئة إنتاج.

## استيراد الحزم
ابدأ باستيراد مساحة الأسماء Aspose.Tasks المطلوبة لتعامل مع المشاريع:

```java
import com.aspose.tasks.*;
```

## الخطوة 1: إعداد دليل المشروع الخاص بك
حدد المجلد الذي يحتوي على ملف `.mpp` الذي تريد تحليله. حفظ المسار في متغير يجعل الكود قابلًا لإعادة الاستخدام وأسهل للاختبار:

```java
String dataDir = "Your Data Directory";
```

*استبدل `"Your Data Directory"` بالمسار المطلق أو النسبي للمجلد الذي يحتوي على `project.mpp`.*

## الخطوة 2: إنشاء كائن قارئ المشروع
الفئة `Project` هي الكائن الأساسي في Aspose.Tasks الذي يمثل ملف Microsoft Project في الذاكرة. تحميل الملف يمنحك وصولًا برمجيًا إلى كل خاصية على مستوى المشروع، بما في ذلك إعدادات العملة:

```java
Project project = new Project(dataDir + "project.mpp");
```

## الخطوة 3: عرض خصائص العملة
تُوفر تعداد `Prj` مفاتيح لخصائص المشروع مثل إعدادات العملة. يمكنك الاستعلام عن كل مفتاح باستخدام `project.get(...)` وتحويل النتيجة إلى نوع قابل للقراءة:

```java
System.out.println("Currency Code : " + project.get(Prj.CURRENCY_CODE).toString());
System.out.println("<br>Currency Digits : " + project.get(Prj.CURRENCY_DIGITS).toString());
System.out.println("<br>Currency Symbol : " + project.get(Prj.CURRENCY_SYMBOL).toString());
System.out.println("Currency Symbol Position : " + project.get(Prj.CURRENCY_SYMBOL_POSITION).toString());
```

**ما ستراه:**  
- **Currency Code** – رمز ISO‑4217 مثل `USD`، `EUR`، `JPY`.  
- **Currency Digits** – عادةً `2` لمعظم العملات، `0` لعملة الين الياباني.  
- **Currency Symbol** – الحرف المعروض في التقارير (`$`، `€`، `¥`).  
- **Currency Symbol Position** – `0` للظهور **قبل** المبلغ، `1` للظهور **بعد** المبلغ.

## كيفية الحصول على رمز العملة java؟
حمّل مشروعك، ثم استدعِ `project.get(Prj.CURRENCY_SYMBOL)`؛ تُعيد الطريقة سلسلة الرمز الدقيقة المستخدمة في الملف. هذه السطر الواحد يكفي لإدخال الرمز في أي واجهة مالية أو محرك تقارير لاحق. يمكنك بعد ذلك تخزين السلسلة في متغير، تسجيلها، أو تمريرها إلى مكونات أخرى تحتاج إلى رمز العملة للعرض أو الحسابات.

## الخطوة 4: إكمال العملية
أظهر أن الاستخراج انتهى بنجاح. هذه الرسالة البسيطة مفيدة عندما يُشغل الكود كجزء من مهمة دفعة أكبر:

```java
System.out.println("Process completed Successfully");
```

## المشكلات الشائعة والحلول
| المشكلة | سبب حدوثها | الحل |
|-------|----------------|-----|
| **FileNotFoundException** | مسار `dataDir` غير صحيح أو اسم الملف مكتوب بخطأ. | تحقق من سلسلة الدليل وتأكد من وجود ملف `.mpp` في الموقع المحدد. |
| **NullPointerException on `project.get(...)`** | الملف لا يحتوي على معلومات عملة (نادر) أو مفتاح الخاصية غير صحيح. | استخدم `project.contains(Prj.CURRENCY_CODE)` للتحقق من وجوده قبل القراءة. |
| **LicenseException** | تشغيل بدون ترخيص Aspose.Tasks صالح في بيئة الإنتاج. | `License license = new License(); license.setLicense("Aspose.Tasks.lic");` يحمل ملف الترخيص قبل إنشاء كائن `Project`. |
| **OutOfMemoryError on large files** | محاولة تحميل ملف .mpp كبير جدًا دون استخدام البث. | Aspose.Tasks يعالج الملفات في وضع الذاكرة المنخفضة؛ تأكد من استخدام الإصدار 24.12 أو أحدث. |
