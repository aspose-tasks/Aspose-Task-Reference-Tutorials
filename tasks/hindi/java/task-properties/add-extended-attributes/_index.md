# Aspose.Tasks Java के साथ टास्क विस्तारित एट्रिब्यूट कैसे बनाएं

## परिचय
इस ट्यूटोरियल में आप सीखेंगे कि **टास्क विस्तारित एट्रिब्यूट बनाएं** Microsoft Project फ़ाइल में Aspose.Tasks for Java का उपयोग करके कैसे बनाते हैं। कस्टम फ़ील्ड जोड़ने से आप प्रोजेक्ट‑विशिष्ट डेटा कैप्चर कर सकते हैं जो बिल्ट‑इन कॉलम में नहीं होता, जिससे रिपोर्टिंग और रिसोर्स प्लानिंग पर अधिक सूक्ष्म नियंत्रण मिलता है। गाइड के अंत तक आप किसी भी टास्क में प्लेन‑टेक्स्ट, लुकअप‑सक्षम, और ड्यूरेशन एट्रिब्यूट जोड़ सकेंगे।

## त्वरित उत्तर
- **विस्तारित एट्रिब्यूट** का क्या अर्थ है? यह एक कस्टम फ़ील्ड है जिसे आप परिभाषित करते हैं और टास्क, रिसोर्सेज़ या असाइनमेंट्स से संलग्न करते हैं।  
- **कौन सी लाइब्रेरी यह क्षमता जोड़ती है?** Aspose.Tasks for Java, एक जावा प्रोजेक्ट मैनेजमेंट लाइब्रेरी।  
- **क्या इसे आज़माने के लिए लाइसेंस चाहिए?** हाँ – Aspose वेबसाइट से 30‑दिन का मुफ्त ट्रायल उपलब्ध है।  
- **क्या मैं लुकअप वैल्यूज़ जोड़ सकता हूँ?** बिल्कुल; आप टेक्स्ट या ड्यूरेशन फ़ील्ड्स के लिए अनुमत मानों की सूची प्रदान कर सकते हैं।  
- **क्या API Java 8 और बाद के संस्करणों के साथ संगत है?** हाँ, यह Java 8+ को सपोर्ट करता है और सभी प्रमुख ऑपरेटिंग सिस्टम्स पर चलता है।

## टास्क विस्तारित एट्रिब्यूट क्या है?
टास्क विस्तारित एट्रिब्यूट एक यूज़र‑डिफाइंड कॉलम है जो प्रोजेक्ट फ़ाइल में प्रत्येक टास्क के लिए अतिरिक्त जानकारी संग्रहीत करता है। यह बिल्ट‑इन फ़ील्ड की तरह व्यवहार करता है लेकिन आप जिस भी डेटा टाइप की आवश्यकता हो, जैसे टेक्स्ट, नंबर, डेट्स, या ड्यूरेशन्स, उसे रख सकता है।

## Aspose.Tasks for Java का उपयोग क्यों करें?
Aspose.Tasks **50+ फ़ाइल फ़ॉर्मैट्स** को सपोर्ट करता है और **10,000+ टास्क** वाले प्रोजेक्ट्स को प्रोसेस कर सकता है बिना Microsoft Project इंस्टॉल किए। लाइब्रेरी पूरी तरह ऑफ़लाइन काम करती है, डेटा प्राइवेसी की गारंटी देती है और एंटरप्राइज़‑स्केल सॉल्यूशन्स के लिए डिटरमिनिस्टिक परफ़ॉर्मेंस प्रदान करती है।

## पूर्वापेक्षाएँ
- बेसिक जावा प्रोग्रामिंग ज्ञान।  
- Aspose.Tasks for Java लाइब्रेरी स्थापित है। आप इसे [website](https://releases.aspose.com/tasks/java/) से डाउनलोड कर सकते हैं।  
- एक जावा IDE (IntelliJ IDEA, Eclipse, या VS Code) आपके मशीन पर सेटअप हो।

## पैकेज इम्पोर्ट करें
`import` स्टेटमेंट्स आपको कोर क्लासेज़ तक पहुँच देते हैं, जैसे `Project`, `ExtendedAttributeDefinition`, और `ExtendedAttribute`।  

`Project` एक Microsoft Project फ़ाइल का प्रतिनिधित्व करता है और इसे पढ़ने, संशोधित करने, और सेव करने के मेथड्स प्रदान करता है।  
`ExtendedAttributeDefinition` एक कस्टम फ़ील्ड को परिभाषित करता है जिसे टास्क, रिसोर्सेज़, या असाइनमेंट्स से संलग्न किया जा सकता है।  
`ExtendedAttribute` एक डिफिनिशन का इंस्टेंस है जो किसी विशिष्ट एंटिटी के लिए वास्तविक वैल्यू रखता है।

## टास्क में प्लेन‑टेक्स्ट विस्तारित एट्रिब्यूट कैसे जोड़ें?
प्लेन‑टेक्स्ट विस्तारित एट्रिब्यूट जोड़ने के लिए, आप पहले प्रोजेक्ट लोड करते हैं, फिर Text टाइप की डिफिनिशन बनाते हैं, उसे प्रोजेक्ट के कलेक्शन में जोड़ते हैं, एक टास्क बनाते हैं, डिफिनिशन से एट्रिब्यूट इंस्टैंसिएट करते हैं, उसका टेक्स्ट वैल्यू सेट करते हैं, टास्क से अटैच करते हैं, और अंत में प्रोजेक्ट को सेव करते हैं।

### 1. दस्तावेज़ डायरेक्टरी पाथ सेट करें
```java
import java.io.IOException;
import com.aspose.tasks.*;
```

### 2. नया प्रोजेक्ट बनाएं
```java
String dataDir = "Your Document Directory";
```

### 3. Text1 प्रकार का विस्तारित एट्रिब्यूट डिफिनिशन बनाएं
```java
Project project = new Project(dataDir + "project.mpp");
```

### 4. प्रोजेक्ट के विस्तारित एट्रिब्यूट्स कलेक्शन में डिफिनिशन जोड़ें
```java
ExtendedAttributeDefinition taskExtendedAttributeText1Definition = ExtendedAttributeDefinition.createTaskDefinition(CustomFieldType.Text, ExtendedAttributeTask.Text1, "Task City Name");
```

### 5. प्रोजेक्ट में एक टास्क जोड़ें
```java
project.getExtendedAttributes().add(taskExtendedAttributeText1Definition);
```

### 6. एट्रिब्यूट डिफिनिशन से एक विस्तारित एट्रिब्यूट बनाएं
```java
Task task = project.getRootTask().getChildren().add("Task 1");
```

### 7. जेनरेटेड विस्तारित एट्रिब्यूट को वैल्यू असाइन करें
```java
ExtendedAttribute taskExtendedAttributeText1 = taskExtendedAttributeText1Definition.createExtendedAttribute();
```

### 8. टास्क में विस्तारित एट्रिब्यूट जोड़ें
```java
taskExtendedAttributeText1.setTextValue("London");
```

### 9. प्रोजेक्ट को सेव करें
```java
task.getExtendedAttributes().add(taskExtendedAttributeText1);
```

## लुकअप विकल्प के साथ टेक्स्ट एट्रिब्यूट कैसे जोड़ें?
लुकअप के साथ टेक्स्ट एट्रिब्यूट जोड़ते समय, आप प्लेन‑टेक्स्ट एट्रिब्यूट की वही स्टेप्स फॉलो करते हैं, लेकिन डिफिनिशन जोड़ने से पहले आप उसके `LookupValues` कलेक्शन को अनुमत स्ट्रिंग्स से भरते हैं। ये वैल्यूज़ Microsoft Project में ड्रॉप‑डाउन लिस्ट के रूप में दिखती हैं, जिससे डेटा कंसिस्टेंसी सुनिश्चित होती है।

## लुकअप विकल्प के साथ ड्यूरेशन एट्रिब्यूट कैसे जोड़ें?
ड्यूरेशन एट्रिब्यूट के लिए लुकअप जोड़ने हेतु, डिफिनिशन बनाते समय `Text1` टाइप को `Duration2` से बदलें, फिर `LookupValues` कलेक्शन को “1 day”, “2 days” आदि ड्यूरेशन स्ट्रिंग्स से भरें। डिफिनिशन प्रोजेक्ट में जोड़ने के बाद, एट्रिब्यूट इंस्टैंस बनाएं, ड्यूरेशन वैल्यू सेट करें, टास्क से अटैच करें, और फ़ाइल को सेव करें।

## सामान्य समस्याएँ और ट्रबलशूटिंग
- **Lookup values not appearing** – सुनिश्चित करें कि आप प्रत्येक लुकअप एंट्री को `LookupValues` कलेक्शन में *पहले* `project.getExtendedAttributes().add(definition)` कॉल करने से पहले जोड़ें।  
- **Attribute value not saved** – सत्यापित करें कि आप `ExtendedAttribute` इंस्टैंस को टास्क में *वैल्यू सेट करने के बाद* जोड़ रहे हैं।  
- **File size grows unexpectedly** – बहुत बड़े प्रोजेक्ट्स के साथ काम करते समय `project.setSaveOptions(new ProjectSaveOptions())` कॉल करने पर विचार करें ताकि इन्क्रिमेंटल सेविंग सक्षम हो सके।
