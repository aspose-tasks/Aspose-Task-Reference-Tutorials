# Aspose.Tasks का उपयोग करके जावा में मुद्रा प्रतीक कैसे प्राप्त करें

## परिचय
इस ट्यूटोरियल में आप Aspose.Tasks for Java API का उपयोग करके Microsoft Project (*.mpp*) फ़ाइलों से **get currency symbol java** और **extract currency code java** प्राप्त करेंगे। Aspose.Tasks उन सभी प्लेटफ़ॉर्म पर काम करता है जो Java का समर्थन करते हैं, इसलिए आपको Microsoft Project की स्थानीय स्थापना की आवश्यकता नहीं है। गाइड के अंत तक आप ISO मुद्रा कोड, डिस्प्ले प्रतीक, दशमलव अंकों की संख्या, और प्रतीक की स्थिति को सीधे प्रोजेक्ट फ़ाइल से पढ़ सकेंगे, जिससे आप रिपोर्ट, ERP सिस्टम या कस्टम डैशबोर्ड में सटीक मौद्रिक मेटाडेटा सम्मिलित कर सकेंगे।

## त्वरित उत्तर
- **What does “get currency symbol java” mean?** यह Java कोड के माध्यम से MS Project फ़ाइल से मुद्रा‑संबंधित मेटाडेटा (कोड, प्रतीक, अंक, स्थिति) प्राप्त करने को दर्शाता है।  
- **Do I need a license to try this?** Aspose.Tasks का एक मुफ्त ट्रायल उपलब्ध है; उत्पादन उपयोग के लिए एक व्यावसायिक लाइसेंस आवश्यक है।  
- **Which JDK version is required?** Java 8 या उससे ऊपर।  
- **Can I modify the currency settings after reading them?** हाँ, Aspose.Tasks आपको मुद्रा सेटिंग्स को पढ़ने और लिखने दोनों की अनुमति देता है।  
- **Is this compatible with all .mpp versions?** API Microsoft Project 2003‑2021 द्वारा निर्मित फ़ाइलों का समर्थन करता है।

## get currency symbol java क्या है?
Aspose.Tasks के साथ एक प्रोजेक्ट लोड करके और उपयुक्त प्रॉपर्टी कुंजियों को कॉल करके आप मूल प्रोजेक्ट फ़ाइल द्वारा उपयोग किए गए मुद्रा प्रतीक को प्राप्त कर सकते हैं। यह ऑपरेशन आपको वह सटीक अक्षर (जैसे `$`, `€`, `¥`) देता है जो Microsoft Project द्वारा उत्पन्न रिपोर्टों में दिखता है। यह मेथड मौद्रिक मानों के लिए उपयोग किए गए सटीक अक्षर को लौटाता है, जिससे उत्पन्न रिपोर्टें मूल प्रोजेक्ट के फ़ॉर्मेटिंग और लोकैल सेटिंग्स से मेल खाती हैं।

## Aspose.Tasks के साथ जावा में मुद्रा प्रॉपर्टीज़ क्यों पढ़ें?
आप Microsoft Project को लॉन्च किए बिना ही मुद्रा सेटिंग्स प्राप्त कर सकते हैं, जिससे समय और सर्वर संसाधनों दोनों की बचत होती है। Aspose.Tasks एक सामान्य 200‑पृष्ठ .mpp फ़ाइल को 30 ms से कम समय में प्रोसेस करता है और पूरी दस्तावेज़ को मेमोरी में लोड किए बिना 500 MB तक की फ़ाइलें संभाल सकता है—एक मापनीय प्रदर्शन दावा जो बड़े पैमाने पर प्रोसेसिंग को संभव बनाता है।

## चरण 1: अपने प्रोजेक्ट डायरेक्टरी को सेट अप करें
उस फ़ोल्डर को परिभाषित करें जिसमें वह `.mpp` फ़ाइल हो जिसे आप विश्लेषण करना चाहते हैं। पाथ को एक वेरिएबल में रखने से कोड पुन: उपयोग योग्य और परीक्षण में आसान बनता है:

```java
String dataDir = "Your Data Directory";
```

*`"Your Data Directory"` को उस फ़ोल्डर के पूर्ण या सापेक्ष पाथ से बदलें जहाँ `project.mpp` स्थित है।*

## चरण 2: एक प्रोजेक्ट रीडर इंस्टेंस बनाएं
`Project` क्लास Aspose.Tasks का मुख्य ऑब्जेक्ट है जो मेमोरी में एक Microsoft Project फ़ाइल का प्रतिनिधित्व करता है। फ़ाइल को लोड करने से आपको प्रत्येक प्रोजेक्ट‑स्तर की प्रॉपर्टी, जिसमें मुद्रा सेटिंग्स भी शामिल हैं, तक प्रोग्रामेटिक पहुँच मिलती है:

```java
Project project = new Project(dataDir + "project.mpp");
```

## चरण 3: मुद्रा प्रॉपर्टीज़ प्रदर्शित करें
`Prj` एनेमरेशन प्रोजेक्ट प्रॉपर्टीज़ जैसे मुद्रा सेटिंग्स के लिए कुंजियाँ प्रदान करता है। आप प्रत्येक कुंजी को `project.get(...)` के साथ क्वेरी कर सकते हैं और परिणाम को एक पठनीय प्रकार में कास्ट कर सकते हैं:

```java
System.out.println("Currency Code : " + project.get(Prj.CURRENCY_CODE).toString());
System.out.println("<br>Currency Digits : " + project.get(Prj.CURRENCY_DIGITS).toString());
System.out.println("<br>Currency Symbol : " + project.get(Prj.CURRENCY_SYMBOL).toString());
System.out.println("Currency Symbol Position : " + project.get(Prj.CURRENCY_SYMBOL_POSITION).toString());
```

**आपको क्या दिखेगा:**  
- **Currency Code** – ISO‑4217 कोड जैसे `USD`, `EUR`, `JPY`।  
- **Currency Digits** – अधिकांश मुद्राओं के लिए आमतौर पर `2`, जापानी येन के लिए `0`।  
- **Currency Symbol** – रिपोर्टों में दिखाया गया अक्षर (`$`, `€`, `¥`)।  
- **Currency Symbol Position** – राशि से **पहले** के लिए `0`, **बाद** के लिए `1`।

## जावा में मुद्रा प्रतीक कैसे प्राप्त करें?
अपने प्रोजेक्ट को लोड करें, फिर `project.get(Prj.CURRENCY_SYMBOL)` को कॉल करें; यह मेथड फ़ाइल द्वारा उपयोग किए गए सटीक प्रतीक स्ट्रिंग को लौटाता है। यह एकल पंक्ति किसी भी डाउनस्ट्रीम वित्तीय UI या रिपोर्टिंग इंजन में प्रतीक को फीड करने के लिए पर्याप्त है। आप इस स्ट्रिंग को एक वेरिएबल में संग्रहीत कर सकते हैं, लॉग कर सकते हैं, या उन अन्य घटकों को पास कर सकते हैं जिन्हें डिस्प्ले या गणना के लिए मुद्रा प्रतीक की आवश्यकता होती है।
